each of the seven steps.

- [ ] What did you expect? — long text
- [ ] What happened? — long text
- [ ] How long did it take you (minutes, not counting waiting)? — number
- [ ] Did you finish this step? — yes / no
- [ ] If not, where did you stop and why? — short text
- [ ] Screenshots — file upload, several allowed

- [ ] Was anything unclear, or wrong about your business? — long text

- [ ] The page's address — short text
