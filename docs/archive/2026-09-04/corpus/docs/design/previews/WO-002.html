Route-group skeleton — the root layout and font wiring

WO-002. This work order writes no screen. It writes the container three later screens render inside: the root document, and the three route groups BP-001 decision 2 fixes with the authorisation rule attached to the group. Drawn plain, deliberately independent of the approved card idiom (`tokens.md` §9) — there is no card here to take an idiom.
