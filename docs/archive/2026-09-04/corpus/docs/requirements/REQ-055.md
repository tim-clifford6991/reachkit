# REQ-055 — Brand voice is one field the customer writes, and nothing is learned about them

- Priority: Should

## User story
As a paying customer, I want to describe how my pages should sound in one piece
of plain text and have that respected, so that drafts read like my business
without the product building a model of me behind my back.

## Rationale
Exactly one thing the customer can read and change decides how their pages sound,
and nothing the product observes about them — their edits, their drafts, their
publishing history — is ever turned into a profile that shapes output they cannot
inspect. Source: `BUILD.md` §8.7 — "Brand voice = one free-text field appended to
the draft prompt. Nothing learned."

## Acceptance criteria
1. Given the customer has written a voice description, when a draft is generated,
   then the generation request carries that description in full and unaltered.
2. Given the customer changes that description, when the next draft is generated,
   then only the current text is carried and no earlier version is carried or
   stored for reuse.
3. Given the customer has written no description, when a draft is generated, then
   it is generated without one and no substitute is inferred.
4. Given any number of edited or published pages, when a draft is generated, then
   the only inputs shaping its voice are that description and the page's own
   evidence; no profile, summary or embedding derived from the customer's edits,
   drafts or publishing history is stored or sent.
5. Given a description that asks for something a generation hard rule forbids —
   an invented persona or author (REQ-050 criterion 4), or a claim on the customer's own
   do-not-claim list (REQ-053) — when a draft is generated, then the hard rule
   prevails, the draft is not queued, and the item follows the hard-rule recovery
   path (REQ-053 criterion 3).

## Non-goals
- Where the customer writes and changes the description — REQ-070's Settings
  card.
- Learning voice from the customer's site, edits or past pages.
- More than one voice per site, or per-page voice overrides.
- Tone presets, style scores or voice suggestions.
