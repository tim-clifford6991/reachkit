# REQ-054 — A page that near-duplicates the customer's published set is never queued

> Superseded by REQ-050, which absorbed this requirement's acceptance criteria
> verbatim (2026-08-30; see `requirements/history/REQ-050-2026-08-30-requirement-cleanup.md`).
> Retired in place; cite REQ-050, not this file.

- Priority: Must

## User story
As a paying customer, I want a page that largely repeats something already on my
site to be stopped before it reaches my calendar, so that I do not accumulate
near-identical pages competing with each other.

## Rationale
Publishing variations of the same page devalues the pages already working and is
the second half of the anti-scaled-content control, so the gate runs before a
candidate ever reaches the customer, compares against everything already on their
site and everything already waiting to go there, and never drops a candidate
without a recorded reason. Source:
`BUILD.md` §8 ("Near-duplicate gate: ≥85% similarity vs the customer's published
set = never queued") and §14.3.

## Acceptance criteria
1. Given a candidate page, when it is compared against every page on the
   customer's own site the product has published or measured and against every
   draft already queued for them and not yet published, then it is queued only if
   it is less than 85 per cent similar to each of them.
2. Given a candidate at or above that similarity, when the gate runs, then it is
   never queued, no page takes its day, and the item follows the hard-rule
   recovery path (REQ-053 criterion 3).
3. Given any two comparisons, when similarity is computed, then it is computed by
   the same single recorded measure, so the same pair of pages always returns the
   same verdict.
4. Given a candidate the gate rejected that the customer had already been shown
   on a day, when that day's line is produced (REQ-043 criterion 4), then the
   cause available to it is that the candidate duplicated an existing page,
   together with the page it duplicated, so the day never empties without an
   explanation.

## Non-goals
- Comparing against pages published by anyone other than this customer.
- Rewriting a rejected candidate to slip under the threshold.
- A customer-adjustable similarity threshold.
- Surfacing candidates that never reached a calendar day.
- The wording of the day's line — REQ-043 owns the one line a day carries; this
  requirement owns only the cause it can carry for a near-duplicate.
