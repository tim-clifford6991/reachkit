# JN-005 — The Monday check-in — is any of this actually working?

Once a week — a Monday, weeks into the subscription, over coffee — the persona
stops using the product and starts judging it. This journey is the renewal
decision: it succeeds when a founder with no SEO knowledge
can answer "is this working?" in under two minutes, from measured values that
each carry their movement or their target, and can see page by page which of
their published pages earned their place. It is separate from the daily loop
because its cadence, its trigger and its question are different — the daily
journey asks "is tomorrow's page right?", this one asks "was the last month worth
paying for?". It fails if a number appears without provenance, if a week with
nothing to report is dressed up with zeros, or if a page that went backwards is
quietly rounded away.
