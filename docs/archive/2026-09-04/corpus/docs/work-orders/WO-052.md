# WO-052 — `Measured<T>` — the three arms, the only constructors, and the total combinators

- Branch: wo/WO-052-measured
- Estimate: ≤1 day

## Goal
Ship the three-armed value every number in the product is stored and rendered
as, with no constructor that can produce one from a nullable number and no
combinator that can drop a reason.

## Interfaces

Consumes: nothing.

Exposes (verbatim from BP-024 `## Public interface`, `src/lib/measure/measured.ts`):

```ts
/** BP-010 declares this type; this node produces it and owns its combinators.
 *  Every stored and rendered number in the product is one of the three arms. */
export type Measured<T> =
  | { kind: 'measured';   value: T; at: Date }
  | { kind: 'zero';       value: T; at: Date }
  | { kind: 'unmeasured'; reason: UnmeasuredReason; at: Date }
export type UnmeasuredReason = 'undeterminable' | 'not_attempted'

/** The only constructors. There is no `Measured.of(number | null)`: a nullable
 *  number cannot say why, and the whole point of REQ-004 is that it must. */
export function measured<T>(value: T, at: Date): Measured<T>
export function measuredZero<T>(zero: T, at: Date): Measured<T>
export function unmeasured<T>(reason: UnmeasuredReason, at: Date): Measured<T>

/** Total combinators. Arithmetic never leaves the type, so no call site can
 *  reach a raw number by accident and no reason is lost on the way. */
export function mapMeasured<A, B>(m: Measured<A>, f: (a: A) => B): Measured<B>
export function combine<A extends readonly Measured<unknown>[], B>(
  parts: A, f: (values: Values<A>) => B
): Measured<B>          // unmeasured if any part is unmeasured — see `worseReason`
export function worseReason(a: UnmeasuredReason, b: UnmeasuredReason): UnmeasuredReason
```

`Values<A>` is the tuple of the `value` types of `A`'s arms; it is a local type
helper of this file and is not part of the exported surface BP-024 declares.

## Steps
1. Write the failing suite first.
2. Declare the union and `UnmeasuredReason`.
3. Implement the three constructors. Export no `of`, no `fromNullable`, no
   `orElse`, and no default parameter that would let `at` be read from a clock.
4. Implement `mapMeasured` — it preserves the arm and the `at`, and never
   touches the `unmeasured` arm's reason.
5. Implement `combine`: if every part is `measured` or `zero`, apply `f` to the
   values and return `measured`; if any part is `unmeasured`, return
   `unmeasured` carrying the fold of every unmeasured part's reason under
   `worseReason`. It never calls `f` when any part is unmeasured.
6. Implement `worseReason` per BP-024 decision 3: `undeterminable` wins whenever
   either side is `undeterminable`.
7. Add the type-level negatives with `@ts-expect-error` so the build fails if
   the guard ever weakens.
