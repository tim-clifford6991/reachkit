# WO-034 — Custom components, part 2 — CalendarGrid and DayPanel

- Branch: wo/WO-034-custom-2
- Estimate: ≤1 day
- Preview: sdlc-factory/docs/design/previews/WO-034.html
- Signed-off: <date>

## Goal
Ship the remaining two custom surfaces — the month grid and the day panel — as
pure layout that renders whatever a caller hands it and states nothing itself.

## Provenance of this file plan
**This repository holds no `src/`.** Every path is NEW under BP-018's `code:`
glob `src/ui/**`, except the custom barrel this work order appends to. Sequenced
after WO-033 for exactly that reason.

## File plan
| File | New/Modify | Change |
|---|---|---|
| `src/ui/components/custom/CalendarGrid.tsx` | NEW | The month grid. Takes `{ date: Date; stage: string; tone: Tone; label: string }[]` — `stage` and `label` both required, so a day can never render as a coloured cell alone. Every date renders through `.num`. Holds no notion of what a stage means and no padding behaviour: an empty day is an absent entry the caller decides about, never a filled-in placeholder. |
| `src/ui/components/custom/DayPanel.tsx` | NEW | The day panel frame. Takes a required heading node, a required account node and an actions slot; supplies none of them and offers no default action. |
| `src/ui/components/custom/index.ts` | MODIFY | Appends the two; the custom set is now exactly the four BP-018 names. |
| `src/ui/components/custom/custom.css` | MODIFY | Adds the grid and panel scopes. Shared with WO-033, which is why these two are sequenced. |
| `tests/ui/custom-2.test.tsx` | NEW | The tests below. |

## Interfaces
Exposes (verbatim from BP-018 `## Public interface`, completing the line):
```ts
export { CalendarGrid, DayPanel, AiDotMatrix, Sidebar } from './components/custom'
```
Consumes: `Tone`, the registered set, the theme and type layers.

## Steps
1. Write `CalendarGrid` with the required label per day.
2. Write `DayPanel` with three required slots and no defaults.
3. Append to the barrel and to `custom.css`; assert the custom set is four.
4. Write the tests; watch the "a day cannot render as colour alone" test fail
   first by making `label` optional.

## Test plan
> **Criterion source: the blueprint, not a requirement — and there is no
> requirement to draw on.** BP-018 has no requirement ancestor.

## Out of scope

  BP-054 and BP-019.
