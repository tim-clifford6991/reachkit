# WO-070 — The landing page — one text input, one submit, and nothing else

- Branch: wo/WO-070-landing
- Estimate: ≤1 day
- Preview: sdlc-factory/docs/design/previews/WO-070.html
- Signed-off: 2026-09-03 — v1 — https://claude.ai/code/artifact/99a116b7-5305-4aad-84dd-3cff31bb3704

## Goal
Serve `/` as one text input and one submit control, with no other input of any
kind, no gate before submitting, and a written line in place when the value is
not a well-formed public domain name.

## File plan

> Every path below is **NEW**. Verified 2026-08-31: this repo carries no `src/`.
> Placement per `structure.md`; `src/app/(public)/page.tsx` is BP-022's inside
> BP-001's `src/app/(public)/**`. Provisional against a repo with no code.

| File | New/Modify | Change |
|---|---|---|
| `src/app/(public)/page.tsx` | NEW | The landing page: one `Input`, one `Btn`, and the copy keys around them. The form posts to `/api/scan`. With JavaScript it posts JSON and navigates to `location`; without it, it is a plain form post that follows WO-062's 303. On a 422 or a returned problem handle it re-renders in place with the value intact and one written line from that handle's key. Reads no session, sets no cookie, renders no gate. |
| `tests/app/scan-address/landing.test.tsx` | NEW | The one-control, no-gate, error-in-place and no-JavaScript suites named in the test plan. |

## Interfaces

Consumes: WO-062's `POST /api/scan` and `StartScanResponse`; WO-051's
`DomainProblem` (type only, to key the written line); BP-019's `copy()`;
BP-018's `Input` and `Btn`.

Exposes (verbatim from BP-022 `## Public interface`):

```
Routes
  GET  /                                    landing: one text input, one submit, nothing else
```

## Steps
1. Produce the preview artifact at the path in the display bullets above and hold
   in draft until it is signed off (rule 7.3).
2. Write the failing suites first.
3. Render exactly one text input and one submit control. Render no select, no
   toggle, no checkbox, no radio, no second text field, optional or required.
4. Wire the JavaScript path: post JSON, then navigate to `location` on `ok: true`;
   on `ok: false` re-render in place with the value intact and the problem's
   written line.
5. Wire the no-JavaScript path: the same form as a plain post; WO-062's 303 to
   the canonical address on success, and its 303 back here carrying the problem
   handle and the value on failure, which this page re-renders in place.
6. Read no session and set no cookie; render no sign-in, no payment and no email
   field anywhere on the page.
