# WO-009 — Baseline schema — the eight tables no other node owns

- Branch: wo/WO-009-baseline
- Estimate: ≤1 day

## Goal
Create, as one baseline migration, the eight tables of `BUILD.md` §10 that no
other node owns a topic token for — with their keys, their indexes and no
foreign key carrying `ON DELETE CASCADE`.

## Provenance of this file plan
**This repository holds no `supabase/migrations/`.** Both paths are NEW, anchored
to BP-002's `code:` glob `supabase/migrations/*_baseline*.sql`.

## File plan
| File | New/Modify | Change |
|---|---|---|
| `supabase/migrations/00000000000001_baseline.sql` | NEW | Eight of the nine tables of `BUILD.md` §10 (all but `fetches` — see `rests-on`) with the key columns it lists: `users` (id, email, plan_status active/past_due/canceled, stripe_customer_id, created_at); `sites` (id, user_id, domain, category, competitors jsonb ≤5, mode autopilot/copilot, veto_hours, publish_time, voice_text, do_not_claim jsonb, created_at); `scans` (id, site_id null for free, domain, tier free/deep/weekly, status running/done/degraded, score, drivers jsonb, report jsonb, cost_cents, created_at); `opportunities`; `drafts`; `publications` — **without `verdict`**; `destinations`; `leads`. Every foreign key from `users` or `sites` is written **without** `ON DELETE CASCADE`. RLS is `enable`d on every table here and left with **no policy**, so the tables are unreadable until WO-010 lands. |
| `tests/db/baseline.test.ts` | NEW | Applies the migration to a scratch database and asserts the schema below. |

## Interfaces
Consumes: nothing. Exposes: the schema every later topic migration extends. This
work order writes no TypeScript type; `Database` is generated in WO-011.

## Steps
1. Write the migration, table by table, in `BUILD.md` §10's order, skipping
   `fetches`.
2. `alter table … enable row level security` on all eight, with no policy.
3. Add the indexes BP-002's NFR budget requires on the request path.
4. Apply to a local database and generate no types yet.
5. Write the tests; watch the "no cascade" test fail first by adding one cascade,
   then remove it.
