# WO-121 — offerTerms and offerAvailable — one offer, one derivation, never before the report

- Branch: wo/WO-121-offer-terms
- Estimate: ≤1 day

## Goal
Derive the offer's terms once, from pins and copy keys, so both surfaces that
carry the offer state the same thing — and answer, for a scan, whether the offer
may be shown at all.

## File plan
> **Every path below is NEW.** No `src/` exists. Anchored to
> `registry/structure.md` (`src/lib/account/**` is BP-017's) and BP-031's `code:`
> glob `src/lib/account/offer/**`. Provisional against a repo with no code.

| File | New/Modify | Change |
|---|---|---|
| `src/lib/account/offer/terms.ts` | NEW | Exports `OfferTerms` and `offerTerms()` exactly as BP-031's public interface declares them. Pure and synchronous; makes no query. `rows[0].value` reads BP-005's daily page cadence pin, `rows[3].value` reads `VETO.defaultHours` (BP-031 decision 4: "`offerTerms().rows` reads `VETO_WINDOW_DEFAULT_HOURS` from BP-005"). `priceKeys` is BP-030's `PRICE_COPY_KEYS`, imported, not restated. **Every word is a copy key; this file contains no sentence.** |
| `src/lib/account/offer/available.ts` | NEW | Exports `offerAvailable(scan)` exactly as BP-031 declares it. `running` and `failed` return `{ show: false; because: 'scan_not_finished' }`; `done` and `degraded` return `{ show: true }` (BP-031: "A degraded pass still produced a report (REQ-029 c3), so `degraded` shows the offer"). Total over the four-member status union — a fifth status is a compile error, not a default branch. |

| `tests/account/offer/available.test.ts` | NEW | One case per scan status, all four; a case asserting that no other input (session, origin, price surface) can change the answer. |

Asserts that the report surface's terms and the price surface's terms are the *same object value* — obtained by calling `offerTerms()` once per consumer and deep-comparing — and that neither consumer can add, drop or reorder a row. |

## Interfaces
Consumes (verbatim from BP-030's `## Public interface`):
```ts
export const PRICE_COPY_KEYS: readonly ['price.amount', 'price.vat_included', 'price.interval']
```
Exposes (verbatim from BP-031's `## Public interface`):
```ts
export interface OfferTerms {
  priceKeys: typeof PRICE_COPY_KEYS               // from BP-030
  rows: readonly [
    { key: 'offer.cadence.page';        value: number },  // pages written per day
    { key: 'offer.cadence.measure';     value: 'weekly' },
    { key: 'offer.cadence.movement';    value: 'weekly' },
    { key: 'offer.veto.window';         value: number },  // default veto hours
  ]
  cancelKey: 'offer.cancel_self_service'
  startKey:  'offer.start'
}
export function offerTerms(): OfferTerms

export function offerAvailable(scan: { status: 'running' | 'done' | 'degraded' | 'failed' }):
  { show: true } | { show: false; because: 'scan_not_finished' }
```
