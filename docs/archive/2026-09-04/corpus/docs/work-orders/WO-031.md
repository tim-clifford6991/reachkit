# WO-031 — Registered components, part 1 — Btn, Card, Badge, Alert, Stat, Tabs, Table, Progress

- Branch: wo/WO-031-components-1
- Estimate: ≤1 day
- Preview: sdlc-factory/docs/design/previews/WO-031.html
- Signed-off: <date>

## Goal
Ship the first eight of BP-018's registered daisyUI components, each with no
default string and every label a required prop.

## Provenance of this file plan
**This repository holds no `src/`.** Every path is NEW under BP-018's `code:`
glob `src/ui/**`.

## File plan
| File | New/Modify | Change |
|---|---|---|
| `src/ui/components/Btn.tsx` | NEW | daisyUI `btn` (+primary/ghost/sm/block). Label is a required prop. |
| `src/ui/components/Card.tsx` | NEW | `card`/`card-body`/`card-title`. `BUILD.md` §2.5: the card leads with the answer, so the title slot takes a verdict node, not a metric label with a default. |
| `src/ui/components/Badge.tsx` | NEW | `badge` (+primary/success/warning/error/ghost), keyed by `Tone`. |
| `src/ui/components/Alert.tsx` | NEW | `alert`, four tones. Message is a required prop; there is no default empty-state sentence. |
| `src/ui/components/Stat.tsx` | NEW | `stats`/`stat`. The big number renders through `.num`, so a numeral cannot ship in the UI font. |
| `src/ui/components/Tabs.tsx` | NEW | `tabs` (boxed + bordered). |
| `src/ui/components/Table.tsx` | NEW | `table` (+zebra), **always inside an `overflow-x-auto` wrap** — the wrap is part of the component, not the caller's job. |
| `src/ui/components/Progress.tsx` | NEW | `progress`. Determinate only: a caller cannot request an indeterminate bar. |
| `src/ui/components/index.ts` | NEW | Barrel exporting these eight. WO-032 appends to it, which is why the two are sequenced and never run in parallel. |
| `src/ui/types.ts` | NEW | `export type Tone = 'ok' \| 'warn' \| 'bad' \| 'neutral' \| 'accent'`, verbatim from BP-018. |
| `tests/ui/components-1.test.tsx` | NEW | The tests below. |

// Series colours are `chart-you` and `chart-rival` only; Tone is for state and

Consumes: `src/ui/theme.css` (WO-029), `src/ui/type.css` (WO-030).

## Steps
1. Write `types.ts` with `Tone`.
2. Write the eight components, each with required label props and no default
   string.
3. Write the barrel.
4. Write the tests; watch the "no component has a default string" test fail first
   by giving `Alert` a fallback message.
