# WO-165 — The empty-date resolver: one account per date, exhausted supply proven, unattributed last

- Branch: wo/WO-165-calendar-empty
- Estimate: ≤1 day

## Goal
Resolve every empty date to exactly one true account, first-match over a fixed
precedence, with `supply_exhausted` returned only on positive proof and
`unattributed` as the last arm.

## File plan

> follows `structure.md` and BP-039's `code:` globs; provisional.

Exposes (verbatim from BP-039 `## Public interface`):
```ts
/** REQ-043 criteria 3, 4 and 5. One account per date, resolved in one fixed
 *  order, total. `supply_exhausted` is a proven arm and is never the fallback —
 *  ADR-061 states why, and the resolver's last arm is `unattributed`. */
export type EmptyAccount =
  | { cause: 'instruction'; opportunityId: string }                  // REQ-047 c5 — outranks all
  | { cause: 'reachkit_stopped'; resumesOn: Date | null }            // REQ-092 c1, c4
  | { cause: 'page_cannot_go_live'; state: 'skipped' | 'unpublished' }
  | { cause: 'customer_change_holds_pages'; setting: 'publishing_off' | 'destination_disconnected' }
  | { cause: 'supply_exhausted'; since: Date }                       // REQ-043 c3 — proven only
  | { cause: 'unattributed' }                                        // ADR-061
export const EMPTY_PRECEDENCE: readonly EmptyAccount['cause'][]
export function accountFor(a: { siteId: string; date: Date }): Promise<EmptyAccount>
```

## Steps
1. **Read ADR-061 before writing a line of this file.** Its precedence is
   `instruction → reachkit_stopped → page_cannot_go_live →
   customer_change_holds_pages → supply_exhausted → unattributed`. Collapsing the
   last two arms into one `else` is the cleanup that makes the product tell
   customers their market is empty on days it merely broke.
2. Write the failing tests first (§8).
3. Implement the resolver as a first match over `EMPTY_PRECEDENCE`, returning on
   the first matching arm.
4. Gate `supply_exhausted` on a **read** of `supplyDepth().unused === 0`. If the
   read fails or is unavailable, fall through to `unattributed`.
5. Render `unattributed` through BP-019's stopped-work line — the same line
   `reachkit_stopped` renders, carrying a resumption date or an explicit
   no-time-promised and naming no internal cause.
6. Emit the `unattributed` counter as a defect signal (BP-039's observability
   line), not as a normal state.
7. Mutation check (the discriminating test ADR-061 names): with supply depth
   unreadable and no other cause matching, assert the resolver returns
   `unattributed` and **not** `supply_exhausted`.
