# WO-072 — deriveMarketSet — the measured market set from keywordSuggestions

- Branch: wo/WO-072-derive-market-set
- Estimate: ≤1 day

## Goal
Implement `src/lib/market/questions/market-set.ts` so a set of seed terms becomes the
`Measured<SuggestionRow[]>` the selection ranks over — as many rows as the vendor
returned and no more, with a market that returned nothing carried through as a
measured-empty rather than an error.

## Context an implementer needs
No source code exists on disk in this repository; every path below is NEW. Placement
is provisional against `sdlc-factory/docs/registry/structure.md`, whose BP-025 glob is
`src/lib/market/questions/**` with tests at `tests/market/questions/**` (rule 4).

## Steps
1. Create the file with `SuggestionRow` and the `deriveMarketSet` signature verbatim.
2. Call `keywordSuggestions(c, { seed, rows: 50 })` for the seeds supplied. Where more
   than one seed is handed in, concatenate the rows in seed order and keep the first
   occurrence of a repeated `keyword` — this is a transport-level identity collapse on
   an exact string, **not** the near-duplicate collapse, which is `stemKey`'s in WO-073.
3. Fold the per-seed `Measured` arms into one: any `measured` arm ⇒ `measured`; all arms
   `zero` ⇒ `zero` with `value: []`; all arms `unmeasured` ⇒ `unmeasured` carrying the
   first arm's `reason`. A vendor that returned no rows is `zero`, never an error and
   never `unmeasured` (BP-007: "An empty payload is always a miss; there is no negative cache" —
   the emptiness is a measurement, the caching is not this file's concern).
4. Emit the observability field BP-025's `## NFR budget` names: the suggestion row count.
5. Write the tests; watch each fail first.

produce a byte-identical row order on repeat runs) and
`deriveMarketSet/exact-duplicate-collapsed-once`.
