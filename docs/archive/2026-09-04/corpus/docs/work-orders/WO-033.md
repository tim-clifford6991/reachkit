**The cell contract** (this WO's — BP-018's public interface declares the export
and no props; `design/components.md` fixes the contract as *"three cell states,
not two"* plus *"row identity (`you` / `rival`) is part of the contract"*, and
the three shapes below are derived from `BUILD.md`'s own words, not chosen):

```ts
/** BUILD §4.1: "rivals' cited rows filled gray, customer's row empty red-ringed,
 *  `n/{m}` per row; a no-AI-answer question = muted cell". §6.2: "render a
 *  no-AI-answer question as a muted cell, never as a miss."
 *  Three states, because a boolean has two and the third — a question Google's
 *  AI never answered — is not a miss the customer earned. Rendering it as one is
 *  REQ-004's null-vs-zero failure arriving through a UI prop. */
export type AiDotMatrixCellState = 'cited' | 'not-cited' | 'muted'

export interface AiDotMatrixCell {
  /** Required. Direct-labelled, per BP-018: identity is never colour-alone. */
  label: string
  state: AiDotMatrixCellState
}

/** Row identity, because §4.1 rings the customer's own empty row and fills
 *  rivals' gray — a per-cell boolean cannot say whose row it is, so the ring is
 *  unexpressible without this. */
export interface AiDotMatrixRow {
  identity: 'you' | 'rival'
  /** Required. The row's own direct label. No default, no derivation here. */
  label: string
  /** The written `n/{m}` for this row, composed by the caller. This component
   *  computes no count and formats no number. */
  count: string
  cells: readonly AiDotMatrixCell[]
}

export function AiDotMatrix(p: { rows: readonly AiDotMatrixRow[] }): JSX.Element
```

`state` and `identity` are internal type members (constitution §1: the system's),
spelled as `design/components.md`'s registered state list spells them — `cited ·
not-cited · muted` — so the registry row and the type do not drift into two
vocabularies. No word in this file is customer-visible: every string a person
reads arrives as a required prop.

## Steps
1. Write `custom.css` scoped to the four named surfaces.
2. Write `Sidebar` and `AiDotMatrix` with every string as a required prop.
   `AiDotMatrix` renders each cell as a total switch over the three states —
   `cited` filled, `not-cited` empty, `muted` muted — with no default arm, so a
   fourth state added later fails the build rather than rendering as one of the
   three. The red ring is the `identity: 'you'` + `not-cited` case and the gray
   fill the `identity: 'rival'` + `cited` case; `muted` renders muted on either
   row, because a question with no AI answer is nobody's miss.
3. Write the barrel with the two.
4. Write the tests; watch the "no legend-only mode" test fail first by adding a
   prop that hides the labels.
