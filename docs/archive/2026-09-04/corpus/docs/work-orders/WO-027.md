# WO-027 — The closed LlmCallSite union and the prompt templates

- Branch: wo/WO-027-call-sites
- Estimate: ≤1 day

## Goal
Make the closed set of things a model is allowed to touch readable in one file
and enforced by the type system.

## Provenance of this file plan
**This repository holds no `src/`.** Every path is NEW under BP-009's `code:`
glob `src/lib/llm/**`. It creates no file WO-026 created.

## File plan
| File | New/Modify | Change |
|---|---|---|
| `src/lib/llm/call-sites.ts` | NEW | `LlmCallSite`, exactly BP-009's seven members with their comments transcribed, plus `LLM_CALL_SITES` as the runtime array and, per member, the tier it is fixed to and the REQ-093 admission (or "text no reader ever sees") it maps to. |
| `src/lib/llm/prompts/profile.ts` | NEW | The `profile` template — homepage and pricing text in, a business profile out. Returns **words**, never a selection. |
| `src/lib/llm/prompts/question-phrasing.ts` | NEW | The `question-phrasing` template — one already-selected search in, that question's wording out. Its input type admits a single search, so a set cannot be handed to it to choose from. |
| `src/lib/llm/prompts/content.ts` | NEW | `brief`, `outline`, `draft`, `answerability` and `claim-check` templates, each with its schema. |
| `src/lib/llm/prompts/opportunity-typing.ts` | NEW | The `opportunity-typing` template — labels an **already-derived** opportunity. |
| `tests/llm/call-sites.test.ts` | NEW | The tests below. |

## Interfaces
Exposes (verbatim from BP-009 `## Public interface`):
```ts
export type LlmCallSite =
  | 'profile'            // nano · homepage+pricing text -> business profile (BUILD 6.7 step 1)
  | 'question-phrasing'  // nano · a selected search -> a question's wording (step 4)
  | 'opportunity-typing' // haiku · label/classify an already-derived opportunity
  | 'brief' | 'outline'  // nano
  | 'draft'              // haiku · grounded draft
  | 'answerability'      // haiku · answerability + SEO pass
  | 'claim-check'        // nano
```
plus `LLM_CALL_SITES` (BP-009's row in `registry/capabilities.md`).
Consumes: `llm()` (WO-026).

## Steps
1. Write the union with its comments transcribed verbatim.
2. Write each template with its Zod schema.
3. Type `question-phrasing`'s input as one search, not a list.
4. Write the tests; watch the "the seam cannot be given a selection decision"
   test fail first by widening that input to an array.
