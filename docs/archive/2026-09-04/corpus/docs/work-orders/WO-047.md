# WO-047 — The cold-start route sweep: no blank, no hidden module, one line per place, nothing borrowed

- Branch: wo/WO-047-coldstart-sweep
- Estimate: ≤1 day

## Goal
Build ADR-010 point 2: enumerate routes from the App Router file tree, render each
against the cold-start fixture, and assert per rendered place that nothing is
blank, nothing is hidden, exactly one written line accounts for it, and every
rendered number traces to the fixture's own measurement.

## File plan
| File | New/Modify | Change |
|---|---|---|
| `tests/presentation/coldstart/routes.ts` | **NEW** | The route enumerator: derives the route set from the App Router file tree under `src/app/**` and `src/app/(hosted)/**` by file convention, returns each route with its source path, and returns the count it enumerated. Takes a root parameter so the fixture route tree is enumerated by the same code. **The one route enumerator in the corpus — WO-050 imports it and must not write a second.** |
| `tests/presentation/coldstart/places.test.ts` | **NEW** | The per-place sweep: renders every enumerated route against the fixture and asserts REQ-091 criterion 2's four properties per rendered place, failing an unregistered place **by name**. Emits the per-place coverage report BP-021's NFR budget requires. |
| `tests/presentation/coldstart/provenance.test.ts` | **NEW** | The provenance assertion: every rendered numeric value traces to a `Measured` whose domain is the fixture's and whose `at` is the fixture scan's date; and no rival, target, question or opportunity appears that the fixture did not produce. |
| `tests/presentation/coldstart/__fixtures__/routes/**` | **NEW** | The synthetic route tree: one clean route per governed glob that must pass, and one violating route per rule that must be flagged by name — a place rendering a bare dash where a value would sit, a module conditionally not rendered when its list is empty, a place carrying two lines, a place absent from `PLACES`, a cohort-average number with no `Measured` behind it, and a rival the fixture never produced. |

## Interfaces
**Consumes** (test-time only — ADR-010 `## Consequences`: reading another node's
tree "creates no import and no cycle; no `depends-on` edge is drawn for it"):
- `PLACES`, `PlaceKey`, `renderPlace`, `account`, `CAUSE_PRECEDENCE` from WO-045.
- `coldStartFixture()`, `degenerateFixture()`, the stubs and
  `COLDSTART_SWEEP_BUDGET_MS` from WO-046. This WO defines no second fixture and
  no second budget (rule 7.2).
- BP-010's `Measured<T>`, type-only, for the provenance assertion.
- The App Router source tree under `src/app/**` and `src/app/(hosted)/**`, read
  from disk. No import of any module in that tree.

**Exposes:** `enumerateRoutes()` to WO-050, which renders the same enumerated
routes twice for the stopped-state sweep.

## Steps
1. Create `routes.ts`. Derive routes from the App Router file convention
   (`page.tsx`, `route.ts`, route groups in parentheses contributing no path
   segment) under a supplied root. Return `{ routes: { path: string; file:
   string }[]; count: number }`. A directory that does not exist yet contributes
   `0` and is reported as `0`, never omitted (rule 5.5).
2. Create the fixture route tree under
   `tests/presentation/coldstart/__fixtures__/routes/` with the six violating
   routes and the clean routes listed in the file plan.
3. Write `places.test.ts`. For each enumerated route, render against the primary
   fixture and walk the rendered output, collecting every place. Assert per place:
   (a) no blank, dash or placeholder stands where a value would sit — a dash is
   admitted only when it came from BP-019's `renderMeasured` on an `unmeasured`
   value, which is REQ-004's trichotomy and not this criterion's business;
   (b) every module in `PLACES` present on that route is still rendered — none
   hidden, dropped or collapsed; (c) every accounted place carries exactly one
   line, and that line is `account()`'s return, not a second string produced at
   the call site; (d) a place rendered but absent from `PLACES` fails **by name**.
   Two describes: one over the fixture route tree (must flag exactly the known
   violations) and one over the real App Router tree (must flag nothing).
4. Write `provenance.test.ts`. For each enumerated route rendered against the
   fixture, collect every rendered numeric value and require each to carry a
   `Measured` whose domain is the fixture's and whose `at` is the fixture scan's
   date. A value with no such provenance fails by origin, not by looking wrong
   (BP-021 `## Error & edge behavior`, eighth bullet). Separately assert that
   every rendered rival, target, question and opportunity appears in the
   fixture's own output. Same two describes.
5. Emit the per-place coverage report BP-021's NFR budget requires: every place
   exercised, and every place found rendered but unregistered. Assert both
   describes' wall clock against `COLDSTART_SWEEP_BUDGET_MS`.
6. Watch each rule fail first: confirm each of the six fixture violations is
   flagged with the rule disabled removed from the expected list, then restore.

## Test plan
| Acceptance criterion (verbatim from REQ-091) | Test |
|---|---|
| 2. "Given that same domain, when any screen the product renders for it is displayed — the report or any screen inside the app, including screens added later — then no blank, dash or placeholder value stands anywhere a value would sit were the customer already present, and no module is hidden, dropped or collapsed for holding nothing yet; each such place, and each such module — including one with no value position at all, such as a list with no entries or a chart with no series — carries exactly one written line, and that line tells the customer they have no presence yet and what will fill it. Where a sibling requirement already fixes the wording for a place, that fixed line is the one line and must itself say both things; where none does, this criterion is what the line must say. A domain that simply has no presence yet is never accounted for as a measurement that could not be taken (REQ-004 criterion 8)." | `places.test.ts` → **"no blank, dash or placeholder stands where a value would sit"**, **"no module is hidden for holding nothing"**, **"every accounted place carries exactly one line"**, and **"a place rendered but unregistered fails by name"** — four named assertions, each run over the fixture route tree (flagging its planted violation) and over the real tree (flagging nothing). The "screens added later" clause is carried by the scope being the App Router file tree, not a list: `routes.ts` holds no route names. Discriminates: deleting any one rule leaves its planted violation unflagged and the fixture describe fails. |
| 3. "Given that same domain, when any screen the product renders for it is displayed, then nothing stands in the place of what the customer does not have: no estimate, benchmark, cohort or category average is presented where a measurement of their own domain would sit, and no rival, target, question or opportunity is manufactured to fill a list that came out empty. Each such place carries criterion 2's written line instead." | `provenance.test.ts` → **"every rendered number traces to the fixture's own measurement"** and **"no rival, target, question or opportunity appears that the fixture did not produce"**. Discriminates: the fixture tree's cohort-average route and its manufactured-rival route must each be flagged; a value passed as a raw number with no `Measured` behind it fails by origin. |
| 1. "Given a domain with no measured rankings and no AI citations of its own, when any scan, derivation, proposal or generation runs for it, then it runs to completion and returns its result — which may legitimately be empty (REQ-029 criterion 4; REQ-047 criterion 3) — and no step fails, blocks, or is skipped for want of prior presence." | Covered by WO-046's `pipeline.test.ts`; this WO consumes that fixture and adds no second assertion of the same criterion (rule 2.4). |
