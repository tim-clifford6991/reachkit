# WO-176 — runWeekly: one measurement inside the week, stamped with the week it belongs to

- Branch: wo/WO-176-weekly-run
- Estimate: ≤1 day

## Goal
Run `runScan({ tier: 'weekly' })` for a due site, stamp the resulting scan with
the site-local `week_start` at insert, and record which parts a degraded run did
not reach — with a second run in one week made unrepresentable rather than
guarded.

```ts
export type UnmeasuredPart =
  | 'rankings' | 'ai_answers' | 'rivals' | 'on_page' | 'verdicts'

export type WeeklyOutcome =
  | { ran: true;  scanId: string; status: 'done' }
  | { ran: true;  scanId: string; status: 'degraded'; unmeasured: readonly UnmeasuredPart[] }
  | { ran: false; because: 'week_not_begun' | 'already_measured' | 'no_active_access' | 'kill_switch' }
export function runWeekly(a: { siteId: string; now: Date }): Promise<WeeklyOutcome>
```

## Steps
1. Write the failing tests first (§8).
2. Refuse before any spend: `week_not_begun`, `already_measured`,
   `no_active_access`, `kill_switch`. The kill switch stops the run before any
   spend (BP-003), and the week then reads `not_measured` with its next due day
   — REQ-092's account, not a silent skip.
3. Compute `week_start` once and write it at insert; never recompute on read
   (BP-050 decision 2).
4. Rely on the partial unique index `(site_id, week_start) where tier =
   'weekly'` for exactly-once — the index, not the schedule, is what makes it
   true (ADR-060 point 3). Map its violation to `already_measured`.
5. Record `unmeasured` parts for a degraded run; a partial week is a
   first-class outcome, not an error, and is never presented as complete.
6. Do not call `judgePublished` for a week with no scan — no movement figure and
   no verdict is produced for such a week.
7. A run that starts and crashes must leave **no** `week_start` row, so the next
   hourly tick retries it inside the same week; a run that completed partially
   leaves a `degraded` row and is not retried.
8. Mutation check: drop the unique-violation handling and run two concurrent
   ticks — the exactly-once test must fail.
