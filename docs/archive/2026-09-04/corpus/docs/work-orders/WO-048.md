# WO-048 — WorkStop and stopCause(): the fact ReachKit stopped, carrying no cause a renderer could leak

- Branch: wo/WO-048-workstop
- Estimate: ≤1 day

## Goal
Create `src/lib/presentation/stopped/stop.ts` so the fact that ReachKit stopped
its own work is representable only in a shape with no cause field, no absent
resumption arm and no absent needs arm.

## File plan
| File | New/Modify | Change |
|---|---|---|
| `src/lib/presentation/stopped/stop.ts` | **NEW** | `WorkStop`, `StopShape` and `stopCause()`. The interface carries no cause field of any kind; `resumes` and `needs` are two-arm unions with no optional member. |
| `tests/presentation/stopped/stop.test.ts` | **NEW** | TST for the three type-level properties criteria 2, 4 and 8 are made out of, and for `stopCause`'s classification of the three stop shapes. |

## Interfaces
**Consumes:** `CopyKey` from `src/lib/presentation/copy` (WO-041), type-only.
Nothing else. The module is pure and "reads no database, calls no job runner and
imports nothing from `src/jobs/`, `src/lib/scan/`, `src/lib/costs/` or
`src/lib/publish/`" (BP-054 `## Module / boundary`).

**Exposes** (verbatim from BP-054 `## Public interface`):
```ts
// ── src/lib/presentation/stopped/stop.ts ─────────────────────────────────────
/** The fact that ReachKit stopped its own work, in the only shape this node
 *  accepts. It carries **no cause field of any kind** — no cap, no spend amount,
 *  no error text, no system status. REQ-092 criterion 8 is unrepresentable
 *  rather than tested for: there is nothing here for a renderer to leak. */
export interface WorkStop {
  /** When ReachKit stopped. Used for "which days does this account for", never
   *  rendered as a cause. */
  since: Date
  /** REQ-092 criterion 4: the date the work is expected to resume, or an explicit
   *  statement that no time is promised. Not optional — "never neither" is the
   *  criterion, and an optional field is exactly how neither happens. */
  resumes: { on: Date } | { promised: false }
  /** REQ-092 criterion 2: whether anything is needed from the customer. The
   *  'nothing' arm is what makes "and when nothing is, says so" a rendered
   *  sentence rather than an omission. */
  needs: { kind: 'nothing' } | { kind: 'action'; key: CopyKey }
  /** REQ-092 criterion 6: the work was cut short but a page was still produced,
   *  so the day states that part of the measurement behind it was not done and
   *  is never presented as a complete pass. */
  partial: boolean
}

/** Classify the three stop shapes REQ-092 criterion 1 names, from facts BP-001's
 *  adapter read. Internal only — the returned handle is never rendered and never
 *  reaches a CopyKey. It exists so the resumption date can be derived per shape
 *  and so a stop can be logged where logging is allowed. */
export type StopShape = 'spend-ceiling' | 'halted' | 'step-failed'
export function stopCause(facts: {
  capHit: boolean; killSwitch: boolean; lastRun: 'ok' | 'degraded' | 'failed'
}): StopShape | null
```

## Steps
1. Create `stop.ts` and declare `WorkStop` exactly as above. Every field is
   required; neither union arm is optional; there is no `cause`, `reason`,
   `shape`, `amount`, `error`, `status` or `detail` field, and none is added
   later — BP-054 `## Error & edge behavior`, second bullet.
2. Declare `StopShape` and implement `stopCause(facts)`. Classification order —
   the order the three shapes are named in REQ-092 criterion 1, and the order
   that makes the strongest fact win: `killSwitch` → `'halted'`; else `capHit` →
   `'spend-ceiling'`; else `lastRun` of `'degraded'` or `'failed'` →
   `'step-failed'`; else `null`. `null` means ReachKit has not stopped and is the
   value that makes every downstream statement render from the other cause set.
3. `stopCause`'s return is never placed in a `WorkStop`, never passed to `copy()`
   and never returned from any function this module exports besides `stopCause`
   itself. Add a source-text assertion for this in the test rather than a comment.
4. The module exports no function that constructs a `WorkStop` from a
   `StopShape`: the resumption date is derived per shape by BP-001's adapter,
   which holds the window boundary this module has no way to read (see the third
   `rests-on` row). This module validates the shape; it does not assemble it.
5. Write `tests/presentation/stopped/stop.test.ts`. Watch it fail before
   `stop.ts` exists.
