# WO-055 — `verdictOf` — the value the top of the report is made of — and the `scans.score` check constraint

- Branch: wo/WO-055-verdict
- Estimate: ≤1 day

## Goal
Compose one `Verdict` — score, band, three factors, what is missing and why, what
else went unmeasured, and the blocked-readers count — and make it impossible for
the stored scalar `scans.score` to disagree with it.

## File plan

> Every path below is **NEW**. Verified 2026-08-31: this repo carries no `src/`
> and no `supabase/`. Placement per `structure.md` (rule 3: migrations are
> topic-prefixed and topic-owned; `*_scans_verdict*` is BP-024's sub-token);
> provisional against a repo with no code.

| File | New/Modify | Change |
|---|---|---|
| `src/lib/measure/verdict.ts` | NEW | `Verdict` and `verdictOf`. Composes WO-054's `factorsOf`/`computeScore`, derives `missing` over factors (never over BP-010's four quantities), derives `unmeasuredElsewhere` from the inputs whose `FEEDS` row is empty of the factors that failed, and computes `blockedReaders` as the count of `AI_READER_AGENTS` members the site's access rules disallow (ADR-022 decision 2). `measuredAt` is a parameter; this file reads no clock. No `tier` field and no `forFree` parameter appears anywhere in it. |

## Interfaces

Consumes: WO-052's `Measured<T>`/`worseReason`; WO-053's `ScanInput`,
`InputOutcome`, `FEEDS`, `classify`; WO-054's `ScoreFactors`, `factorsOf`,
`computeScore`, `BandHandle`; WO-051's `CanonicalDomain`; BP-005's
`AI_READER_AGENTS`; BP-006's `RobotsPolicy`, imported from WO-018's
`src/lib/egress/types.ts` — the declared six-field interface, read through
`disallowedAgents` and `absent` and through no other field.

Exposes (verbatim from BP-024 `## Public interface`, `src/lib/measure/verdict.ts`):

```ts
/** What the top of the report is made of. There is no tier field and no
 *  `forFree` parameter anywhere in this file: REQ-004 criterion 5's "no part …
 *  hidden, blurred, rounded down, locked, or marked as available on payment" is
 *  discharged by there being nothing to pass that could hide anything. */
export interface Verdict {
  domain: CanonicalDomain
  measuredAt: Date                       // one date; every figure under it is this scan's
  scoreAndBand: Measured<{ score: number; band: BandHandle }>
  factors: ScoreFactors
  /** REQ-004 criterion 3: name every factor with no value and, for each, which
   *  of the two reasons applies. Empty when the score could be computed. */
  missing: readonly { factor: ScoreFactorName; reason: UnmeasuredReason }[]
  /** REQ-004 criterion 6, the "no driver depended on it" case, and criterion 10. */
  unmeasuredElsewhere: readonly { input: ScanInput; reason: UnmeasuredReason }[]
  /** Read here because REQ-009 criteria 1, 3 and 4 are a rendering of a
   *  measurement this node performs; BP-027 renders it and computes nothing. */
  blockedReaders: Measured<number>
}
export function verdictOf(a: {
  domain: CanonicalDomain; measuredAt: Date
  drivers: Drivers; inputs: Readonly<Record<ScanInput, InputOutcome>>
  robots: Measured<RobotsPolicy>
}): Verdict
```

## Steps
1. Write the failing suites first.
2. Implement `verdictOf`: factors from `factorsOf`, score from `computeScore`.
3. Derive `missing`: one entry per factor whose arm is `unmeasured`, carrying that
   arm's reason. Empty when the score is `measured` or `zero`.
4. Derive `unmeasuredElsewhere`: one entry per `ScanInput` whose `InputOutcome`
   is `read: false` and whose `FEEDS` row contains no factor that is itself
   missing — REQ-004 criterion 6's "where no driver depended on that input".
5. Derive `blockedReaders`: carry `robots`' arm through with `mapMeasured`,
   counting the members of `AI_READER_AGENTS` for which
   `policy.disallowedAgents[token] === true` — the closed set is applied here,
   which is what BP-006 means by "applied by the caller, not here", and a token
   absent from the map is not disallowed. `policy.absent === true` is a **read
   with nothing in it**: the count is a measured 0 (REQ-004 criterion 7), never
   an `unmeasured`. `disallowsAll === true` disallows every member of the set.
   An `unmeasured` robots value yields an `unmeasured` count with the same
   reason — never 0.
6. Assert on the way out that every `Measured` value inside the verdict carries
   the same `at` as `measuredAt`; a mismatch throws, per BP-024's "a value whose
   `at` differs from the verdict's is a test failure".
7. Write the migration with the constraint verbatim. Do not add a column.
8. Add the determinism test: same inputs twice, byte-identical JSON.
