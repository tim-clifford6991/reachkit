# WO-025 — DataForSEO SERP and AI — serpOrganic, aiMode, llmScraper

- Branch: wo/WO-025-serp-ai-endpoints
- Estimate: ≤1 day

## Goal
Implement the three search and AI-answer endpoints, with `serpOrganic` returning
the `ai_overview` item and its reference domains inside the SERP the product
already buys — the free AI matrix at no extra cost.

## Provenance of this file plan
**This repository holds no `src/`.** Every path is NEW under BP-008's `code:`
glob `src/lib/vendors/**`. It is sequenced after WO-024 because both re-export
from `index.ts`.

## File plan
| File | New/Modify | Change |
|---|---|---|
| `src/lib/vendors/dataforseo/serp.ts` | NEW | `serpOrganic`. Depth 10, `SERP_LOCATION` fixed, `mode` required. Parses organic top-10 **and** the `ai_overview` item with its per-domain `references` into `SerpResult`. **Never sets `load_async_ai_overview`** — it is on the never-list and no code path can set it. Price from `PRICE_BOOK.SERP_LIVE_C` / `SERP_STD_C`. |
| `src/lib/vendors/dataforseo/ai.ts` | NEW | `aiMode` and `llmScraper`, both paid-battery only. `llmScraper` takes `mode: 'std'` and nothing else — there is no live variant to call. Prices from `AI_MODE_LIVE_C` / `AI_MODE_STD_C` / `CHATGPT_SCRAPE_STD_C`. |
| `src/lib/vendors/dataforseo/index.ts` | MODIFY | Re-exports the three; the closed list is now complete at six. |
| `tests/vendors/serp-ai.test.ts` | NEW | The tests below. |
