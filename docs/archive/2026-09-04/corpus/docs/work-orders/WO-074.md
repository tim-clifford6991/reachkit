# WO-074 — selectTwelve — the deterministic selection, its floor, its collapse and its composition constraints

- Branch: wo/WO-074-select-twelve
- Estimate: ≤1 day

## Goal
Complete `src/lib/market/questions/select.ts` with `selectTwelve` — a pure function of a
profile and a market that returns 0…12 searches in a byte-identical order on every run,
padding nothing to reach twelve.

## Context an implementer needs
No source code exists on disk beyond what WO-071, WO-072 and WO-073 land; the two paths
below are NEW files this WO creates or completes. **This WO modifies `select.ts`, the file
WO-073 creates — the two are sequenced (`depends-on`) and must never be run in parallel.**

## Interfaces
**Consumes**: `Profile` (WO-071), `SuggestionRow` (WO-072), and this file's own
`classifyIntent` / `intentWeight` / `passesRelevanceGuard` / `stemKey` (WO-073), plus
`SELECTION` and `BATTERY.QUESTIONS` from `src/lib/config/constants.ts` (BP-005).

**Exposes** — copied exactly from BP-025's `## Public interface`:

```ts
export interface SelectedSearch {
  keyword: string; volume: number; intent: Intent; score: number; rank: number
}
export function selectTwelve(a: { profile: Profile; market: SuggestionRow[] }): SelectedSearch[]
```

and, from BP-011's `## Public interface`, the scoring law this WO implements:

```
/** Deterministic. No model call. score = intentWeight x log10(volume+1), volume
 *  floor 50/mo, own-brand dropped, relevance guard against the profile's
 *  vocabulary, near-duplicate collapse, composition constraints. Returns as many
 *  as the market yielded — never padded to twelve. */
```

## Steps
1. Drop every row whose `volume` is below `SELECTION.volumeFloorPerMonth`.
2. Drop every row whose `classifyIntent` is `'own_brand'`.
3. Drop every row failing `passesRelevanceGuard`.
4. Collapse near-duplicates on `stemKey`, keeping the highest `volume` of each group; on
   an exact volume tie keep the keyword that sorts first, so the collapse is total.
5. Score: `score = intentWeight(keyword, profile) * log10(volume + 1)`.
6. Rank by `score` descending, then `volume` descending, then `keyword` ascending — a total
   order, so no two runs over identical input differ. (Chosen here under rule 1.1 by the
   same reasoning BP-026 decision 3 records for rivals; BUILD §6.7 fixes the score and not
   the order among equals. Cost of reversing: none stored — it changes which of two
   equal-scoring searches is shown.)
7. Apply the composition constraints over the ranked list up to `BATTERY.QUESTIONS`:
   caps `SELECTION.maxRivalBrand` (searches naming one of `profile.namedRivals`) and
   `SELECTION.maxHowTo` (informational how-to shapes) are enforced by skipping a row that
   would exceed them; floors `SELECTION.minDecision` and `SELECTION.minSolution` are
   enforced by promoting the next-ranked row of that intent. **Relax in one fixed order —
   floors first** (BP-025 `## Error & edge behavior`): a floor that cannot be met means the
   market yielded fewer than twelve, which is legal.
8. Assign `rank` 1…n in final order and return. There is **no** code path in this function
   that duplicates a row, repeats a keyword, or appends a row absent from `market`.
9. Emit the observability fields BP-025 names: the selected count and which constraint bound it.
10. Write the tests; watch each fail first.

Determinism, required by BP-025's `## NFR budget`:
`tests/market/questions/select.test.ts › selectTwelve/byte-identical-on-every-run` — the
frozen fixture selected 100 times, and selected again over a shuffled copy of the same
market rows, yields an identical `SelectedSearch[]` including `rank` and `score`.

Purity, required by BP-025 decision 1:
`selectTwelve/takes-no-cost-context` — the signature accepts exactly one argument object
of `{ profile, market }`, and `select.ts` resolves no import into `src/lib/costs/`,
`src/lib/llm/` or `src/lib/vendors/`.

Discrimination: making the rank comparator partial (dropping the `keyword` tie-break),
padding the result to twelve, or moving the relaxation order to caps-first must each fail
a named test above.
