# WO-007 — tests/pins.test.ts — every pin asserted against its quoted source clause

- Branch: wo/WO-007-pins-test
- Estimate: ≤1 day

## Goal
Assert every constant in `src/lib/config/constants.ts` against the source clause
it was pinned from, by quotation rather than by line number, so a drifted
constant fails before anything expensive runs.

## Provenance of this file plan
**This repository holds no `tests/`.** The path is NEW; `structure.md` names
`tests/pins.test.ts` explicitly as BP-005's and rule 4 makes it BP-005's alone.

## File plan
> One file only, so this work order shares no file with any other in the block.

| File | New/Modify | Change |
|---|---|---|
| `tests/pins.test.ts` | NEW | One assertion block per constant group, each opening with the verbatim source quotation it asserts against (`BUILD.md` §6.1's price-book row, REQ-059 criterion 4's agent membership, ADR-060's site-local hour, and so on) and the artifact it came from. Includes the ADR-001 disjointness assertion BP-005 decision 2 requires — **asserted, not skipped**: BP-019 decision 6 records the nine ruled words, so `BAND_LABELS` exists and the intersection of the two rendered sets is asserted empty. Includes the `SCORE_BAND_BOUNDS` block against `BUILD.md` §5, quoted. |

## Interfaces
Consumes (verbatim from BP-005 `## Public interface`): every exported group of
`src/lib/config/constants.ts` and `export const env: Readonly<Env>`.
Exposes: no runtime interface. It exposes the CI gate BP-005's NFR budget names.

## Steps
1. Write one block per group; each begins with the quoted clause (rule 5.3 —
   "`path + verbatim quote`", never `file:line`).
2. Assert `AI_READER_AGENTS` equals REQ-059 criterion 4's six named agents,
   quoting the criterion; assert non-empty separately so an empty list fails
   loudly.
3. Assert `WEEKLY_DUE_HOUR_LOCAL` is site-local and that no UTC hour is pinned,
   quoting ADR-060 — `BUILD.md` §11 says `Mon 06:00 UTC` in writing and this
   assertion is the landmine BP-003's NFR budget names.
4. Write the ADR-001 disjointness block as a live assertion over BP-019's
   `BAND_LABELS`: resolve the six `CopyKey`s through the registry and assert the
   intersection of `{winnability}` and `{rivalSize}` rendered terms is empty
   (REQ-096 criterion 9). The block carries no `skip` and no conditional guard —
   the words exist (BP-019 decision 6) and a skip here would be a check that
   looks like it holds and does not.
5. Write the `SCORE_BAND_BOUNDS` block quoting `BUILD.md` §5 verbatim — "Bands:
   0–24 Invisible · 25–49 Hard to find · 50–74 Findable · 75–100 Dominant" — and
   assert the four lower bounds are 0, 25, 50, 75 and that the constant holds no
   band word. Assert alongside it that `GOAL_VALUES.pages_published === 30`
   against BP-005 decision 3's ruling line, quoted.
6. Watch each block fail first by perturbing the constant, then restore.
