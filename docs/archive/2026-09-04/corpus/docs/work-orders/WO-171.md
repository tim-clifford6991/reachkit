# WO-171 — Copy it out: Markdown and HTML for any draft or published page, one renderer

- Branch: wo/WO-171-draft-export
- Estimate: ≤1 day

## Goal
Serve `GET /api/drafts/{id}/export?as=md|html` for any draft or published page,
whatever its destination, rendering HTML through the same Markdown renderer the
hosted template uses.

## File plan
> Every path below is **NEW** (no `src/` on disk, checked 2026-08-31). Placement
> follows `structure.md` and BP-044's `code:` globs; provisional.

| File | New/Modify | Change |
|---|---|---|
| `src/app/api/drafts/[id]/export/route.ts` | NEW | The `GET` adapter: session plus draft ownership, `as=md` returns `body_md` unchanged, `as=html` returns the render from BP-004's Markdown renderer — one renderer, so the copied HTML and the published HTML cannot differ (BP-044 decision 3). Available for a draft and for a published page alike. |
| `tests/app/draft/export.test.ts` | NEW | Both formats, both lifecycle states, every destination kind, renderer identity, ownership. |

## Interfaces
Consumes: BP-004's hosted-template Markdown renderer (shared, not
re-implemented), `db()` (BP-002).

Exposes (verbatim from BP-044 `## Public interface`):
```ts
/** GET /api/drafts/{id}/export?as=md|html — criterion 12, any draft or published
 *  page, whatever its destination. */
export async function GET(req: Request, ctx: { params: { id: string } }): Promise<Response>
```

## Steps
1. Write the failing tests first (§8).
2. Return `body_md` verbatim for `as=md`; an unedited page's export is identical
   to `body_md_generated` by construction.
3. Render `as=html` through BP-004's renderer — **import it, do not write a
   second one**; a second renderer means the copied HTML and the published HTML
   differ, and the customer is the publisher of record for whichever they use.
4. Authorise session plus draft ownership on this route as on every other.
5. Serve the export whatever the destination — hosted, WordPress, or a
   destination ReachKit does not serve; that is exactly the case this route
   exists for (`BUILD.md` §9).
6. Mutation check: swap in a second Markdown renderer and confirm the
   renderer-identity test fails.
