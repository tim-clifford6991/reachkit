# WO-178 — The settings allow-list: a closed tuple, whole-request rejection, and no home for an engine parameter

- Branch: wo/WO-178-settings-write
- Estimate: ≤1 day

## Goal
Make `SETTABLE` the closed list of what may be written, reject any request
carrying a key outside it without touching a stored value, and prove by test
that no pinned engine parameter is settable.

## Interfaces
Consumes: `db()` and RLS default-deny (BP-002), the pinned key set of
`src/lib/config/constants.ts` (BP-005), `copy()` (BP-019), and the downstream
owners of each setting (BP-011/BP-056, BP-015/BP-057, BP-016/BP-059,
BP-017) — including, verbatim from BP-057's `## Public interface`, the one home
of the publishing rules:
```ts
export function savePublishingSettings(
  siteId: string, patch: Partial<PublishingSettings>, by: Actor
): Promise<
  | { ok: true; settings: PublishingSettings; applied: { draftIds: string[]; retellOwed: string[] } }
  | { ok: false; invalid: readonly ('mode' | 'vetoHours' | 'publishTime' | 'timezone')[] }
>
```

Exposes (verbatim from BP-055 `## Public interface`):
```ts
/** REQ-070 criterion 1's list, as a closed tuple. A key absent from it cannot be
 *  written, because `SettableKey` is derived from it and the handler validates
 *  against it before any row is touched. */
export const SETTABLE = [
  'category', 'competitors', 'domain',
  'mode', 'veto_hours', 'publish_time', 'time_zone', 'publishing_enabled',
  'destinations', 'voice_text', 'do_not_claim', 'notifications',
  'name', 'email',
] as const
export type SettableKey = (typeof SETTABLE)[number]
export type SettingsPatch = Partial<Record<SettableKey, unknown>>

/** REQ-070 criterion 2's list. Each is an action, not a setting; each delegates. */
export const ACTIONS = [
  'invoices', 'cancel', 'resume', 'sign_out', 'export', 'unpublish_all', 'delete_account',
] as const
export type ActionKey = (typeof ACTIONS)[number]

/** Criterion 4: an unknown key rejects the whole request and nothing is stored. */
export type PatchResult =
  | { ok: true; applied: readonly SettableKey[]; effective: 'now' | 'next_weekly' }
  | { ok: false; refused: 'unknown_key'; keys: readonly string[] }
  | { ok: false; refused: 'invalid_value'; key: SettableKey; reasonKey: CopyKey }
  | { ok: false; refused: 'not_owner' }
export function applySettings(a: { siteId: string; patch: SettingsPatch }): Promise<PatchResult>

// POST /api/settings — the only write path; siteId comes from the session.
export async function POST(req: Request): Promise<Response>
```

## Steps
1. Write the failing tests first (§8, "Watch it fail first").
2. Declare both tuples exactly as above — fourteen settings and seven actions.
3. Validate the entire patch before any write. A patch mixing one valid and one
   invalid key writes **nothing**; partial application is not a degraded success
   (BP-055 decision 1).
4. Forward the four publishing keys to BP-057's `savePublishingSettings` and map
   its refusal onto `PatchResult`. Write **no** veto-window arithmetic in this
   file — no `% 24`, no `0`/`168` bound, no days-to-hours conversion. BP-057
   decision 1 puts that conversion in one module and BP-055 cites it rather than
   restating it; a second copy here is the copy that goes stale, and the pair
   already disagreed once (BP-055's interface comment read `0..168`, admitting a
   37-hour window no screen can render — corrected 2026-08-31).
5. Resolve `siteId` from the session; the request body has no site field, so a
   cross-site write is unrepresentable rather than checked (BP-055 decision 2).
   RLS is the backstop, not the only check.
6. Add the disjointness test: `SETTABLE` ∩ exported keys of
   `src/lib/config/constants.ts` = ∅. A pinned engine parameter that ever
   becomes settable fails it (criterion 3, BP-055 decision 3).
7. Surface a vendor or database error as one written line from the registry; no
   error payload reaches the response body.
8. Mutation check: strip unknown keys and apply the rest — the whole-request
   test must fail. Add a pinned constant to `SETTABLE` — the disjointness test
   must fail.
