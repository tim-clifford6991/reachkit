# WO-024 — DataForSEO Labs — rankedKeywords, keywordSuggestions, competitorsDomain

- Branch: wo/WO-024-labs-endpoints
- Estimate: ≤1 day

## Goal
Implement the three Labs endpoints `BUILD.md` §6.3 admits, each priced, cached
and cost-contexted, returning product types rather than vendor payloads.

**Risk: high — seam: money.** Three billable Labs endpoints, each priced against the price book, each cost-contexted and each cached. A price test or a cache-key test that survives deletion bills the product on every call and shows nothing on any screen — the exact failure the charter's cost envelope ("Enforced in the seam, not assumed. Caps are hard") is written against. Mutation-tested (doctrine 0.13.2, rule 2b).

## Provenance of this file plan
**This repository holds no `src/`.** Every path is NEW under BP-008's `code:`
glob `src/lib/vendors/**`. It shares no file with WO-025.

## File plan
| File | New/Modify | Change |
|---|---|---|
| `src/lib/vendors/dataforseo/labs.ts` | NEW | `rankedKeywords`, `keywordSuggestions`, `competitorsDomain`. Each wraps its call in `c.recordFetch({ source, cacheKey, freshnessDays, costCents, run })` with the cost taken from `PRICE_BOOK` and the freshness from `CACHE_WINDOWS_D` (own 7d, rival 30d, suggestions 30d) — never a literal. ## Interfaces
Exposes (verbatim from BP-008 `## Public interface`):
```ts
export function rankedKeywords(c: CostContext, a: { domain: string; rows: 50|100|300 }): Promise<Measured<RankedRow[]>>
export function keywordSuggestions(c: CostContext, a: { seed: string; rows: 50 }): Promise<Measured<SuggestionRow[]>>
export function competitorsDomain(c: CostContext, a: { domain: string }): Promise<Measured<CompetitorRow[]>>
```
Consumes: `transport.ts` (WO-023), `CostContext` (BP-007), `PRICE_BOOK` and
`CACHE_WINDOWS_D` (BP-005).

## Steps
1. Implement the three against `transport.ts`.
2. Wire each price from `PRICE_BOOK` and each window from `CACHE_WINDOWS_D`.
3. Write the tests; watch the "zero rows is measured, not unmeasured" test fail
   first by mapping an empty array to `unmeasured`.
