# WO-280 — The current-report pointer and the one address — two current reports made unrepresentable by the database, and every written form of a domain redirecting to one place

- Branch: wo/WO-280-stored-report-address
- Estimate: ≤1 day

## Goal
Make two current reports for one domain unrepresentable in the database — the four pointer columns and the partial unique index BP-012 decision 1 names — and make every written form of a domain redirect to the single public report address for it.

**Risk: high — seam: a state machine that publishes (§8).** `is_current` is the pointer that decides which stored report is the public one at an address; the partial unique index is the only thing standing between one domain and two simultaneously-published reports, and REQ-001 c17's "no report at that address ever carries measurements from two different scans" rests on it holding in the database rather than in application code. A test that survives dropping the `where is_current` predicate leaves that promise unenforced. This order's own test plan already demands that mutation; `risk: high` is what makes the validator run it (doctrine 0.13.2, rule 2b).

## Steps
1. Write the failing suites first.
2. Write the migration. The partial unique index is the point: BP-012 decision 1
   — "a partial unique index, not application logic, enforces one current
   report" — so no trigger, no application-level lock and no `select … for
   update` appears anywhere in this work order.
3. Mutate to prove the suite discriminates: (a) drop the `where is_current`
   predicate from the index and confirm the two-current-rows case passes an
   insert it should reject; (b) make the version guard return `null` instead of
   throwing and confirm the guard row fails, since `null` is indistinguishable
   from "no report" at every call site.
4. Implement `canonicalRedirect` over `parseDomain`: on `ok`, compare the
   canonical key's URL form with the segment as written; differ → `{ redirectTo }`,
   same → `null`. On a parse failure return `null` — a malformed segment is row 1
   of the resolution table, not a redirect.
