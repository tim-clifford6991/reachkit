# WO-147 — The setup screen: three card slots, the site address, one submit, no duration

- Branch: wo/WO-147-setup-page
- Estimate: ≤1 day
- Preview: sdlc-factory/docs/design/previews/WO-147.html
- Signed-off: <date>

## Goal
Render the one post-payment screen — three card slots, the site address, one
submit control — with no engine control and no statement of how long anything
will take.

## File plan
> Every path below is **NEW** (no `src/` on disk, checked 2026-08-31;
> `00-project.md`: "Greenfield. No source code on disk yet"). Placement follows
> `structure.md` and BP-033's `code:` globs, which glob
> `src/app/(account)/setup/*.tsx` **one level only** — the cards' own directory
> is deliberately not globbed here. Provisional against a repo with no code.

| File | New/Modify | Change |
|---|---|---|
| `src/app/(account)/setup/page.tsx` | NEW | Server component. Renders the address field and three card slots in one `<form>` with one submit control posting to `/api/setup`. Reads the site's measured domain (BP-012's current report) to pre-fill the address, or asks outright where there is none. Every string comes from `copy()`; the file contains no literal sentence and no duration key. |
| `src/app/(account)/setup/SetupForm.tsx` | NEW | Client component holding the submission state for the closed `SetupSubmission` shape and the single submit; disables re-submit while in flight. Renders the three card slots as children — it imports no card. |
| `tests/app/setup/page.test.tsx` | NEW | Screen contract: exactly three decision slots plus the address, one submit, no engine control, no duration string. |

## Steps
1. **Precondition (rule 7.3):** do not start until this WO's preview is signed
   off. As of 2026-08-31 `sdlc-factory/docs/design/tokens.md` is `Status: ready`
   and `components.md` registers 24 components, **every one `proposed`**; a row
   reaches `approved` only when a preview carrying it is signed off, so the
   preview — not the registration — is the gate this step names.
2. Write the failing screen tests first.
3. Render the address field, the three card slots and one submit control. The
   submit control's label is a copy key with **no duration in it** — `BUILD.md`
   §4.3's footer *"Start — first page in ~3 minutes"* is not built (BP-033
   decision 1; REQ-025 criterion 1 forbids it).
4. Assert in test, not in review, that the rendered tree contains no control
   whose name matches the engine-parameter set (question counts, cadences,
   spend caps, scan depth, model choices).
5. On refusal, keep the three decisions on the screen exactly as entered and
   render the refusal's written line from the registry.
6. Mutation check: add a duration string to the submit label and confirm the
   no-duration test fails.
