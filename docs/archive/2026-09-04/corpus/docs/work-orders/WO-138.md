# WO-138 — contentSummary and buildManifest — a plain count, and the archive's shape

- Branch: wo/WO-138-export-manifest
- Estimate: ≤1 day

## Goal
Count every page ReachKit wrote for a site — published, in review, vetoed and
failed alike — and describe the archive's contents as a manifest a test can assert
against without unzipping anything.

## File plan
> **Every path below is NEW.** This repository carries no `src/`. Anchored to
> `registry/structure.md` (`src/lib/account/**` is BP-017's) and BP-062's `code:`
> glob `src/lib/account/export/**`. Provisional against a repo with no code.
>
> BP-062 owns **no** migration topic: "an export reads `drafts`, `publications`
> and their assets and writes nothing." This work order creates no migration, and
> that is deliberate rather than an omission.

| File | New/Modify | Change |
|---|---|---|
| `src/lib/account/export/summary.ts` | NEW | Exports `contentSummary(siteId)` with BP-062's signature verbatim. Returns `{ pages: number }` — **a plain number, not a `Measured<T>`** (BP-062 decision 3: a count of ReachKit's own rows is always knowable, and wrapping it "makes 'we don't know how many pages we wrote for you' a representable state on the one screen where it would read as data loss"). Counts all four states. |
| `src/lib/account/export/manifest.ts` | NEW | Exports `ExportManifest` and `buildManifest(siteId)` with BP-062's signatures verbatim. Order is `created_at` ascending, so an export is byte-stable across runs. Slugs are `pages/<slug>.md`, **never a title**, with `-2`, `-3` collision suffixes applied in manifest order. `publishedAt`, `liveUrl` and `unpublishedAt` are `null` where they do not apply — nulls, never absent keys, "so a reader must be able to tell 'not published' from 'we forgot'". |
| `tests/account/export/summary.test.ts` | NEW | A site with pages in all four states counts all four; a site with zero pages returns 0 and 0 is a true count, not an empty state or a failure; the return type is `number` and a source-level assertion that `summary.ts` imports no `Measured` symbol (decision 3 made enforceable). |
| `tests/account/export/manifest.test.ts` | NEW | Every state appears; two drafts sharing a title get `-2`; the order is `created_at` ascending and two runs produce an identical manifest; a never-published page carries three explicit nulls and no absent key; assets are listed as `assets/<page-slug>/<file>`; a page whose title contains path separators or dots still yields a safe `pages/<slug>.md` path. |

## Interfaces
Exposes (verbatim from BP-062's `## Public interface`):
```ts
export function contentSummary(siteId: string): Promise<{ pages: number }>

export interface ExportManifest {
  pages: ReadonlyArray<{
    path: string                 // `pages/<slug>.md`, collision-suffixed, never a title
    title: string
    state: 'published' | 'in_review' | 'vetoed' | 'failed'
    publishedAt: Date | null     // criterion 4
    liveUrl: string | null       // criterion 4
    unpublishedAt: Date | null   // criterion 4, where no longer published
    assets: readonly string[]    // `assets/<page-slug>/<file>`
  }>
}
export function buildManifest(siteId: string): Promise<ExportManifest>
```
Consumes: `drafts` (`title`, `body_md`, `meta` — BP-014) and `publications`
(`live_url`, `published_at`, `unpublished_at` — BP-015), read-only;
`db()` (BP-002).

## Steps
1. Write `tests/account/export/manifest.test.ts` and watch every case fail.
2. Write `manifest.ts`, deterministic ordering first, collisions second.
3. Write `summary.ts` and its no-`Measured` assertion.
