# WO-241 — `GET /pricing` — the scanless offer surface

- Branch: wo/WO-241-pricing
- Estimate: ≤1 day
- Preview: sdlc-factory/docs/design/previews/WO-241.html
- Signed-off: <date>

## Goal
Serve the one price surface that stands away from any report — exactly one
offer, the terms stated on the same terms the report's offer states them, and
one control that begins checkout with nothing asked first.

## Provenance of this file plan
**This repository holds no `src/`.** Both paths are NEW. `/pricing` is
`structure.md`'s row for BP-001 ("`/` · `/scan/{domain}` · `/pricing` · …") and
BP-001's own route list; it is anchored by this container's glob
`src/app/(public)/**` and by no leaf's, which BP-001's `## Public interface`
records as correct ownership rather than an omission: "None of these is a
candidate for a new feature node … the seventh, `/pricing`, is a rendered
surface whose every input is another node's and which BP-030 and BP-031 each
name as 'outside this boundary … BP-001's'."

## File plan
| File | New/Modify | Change |
|---|---|---|
| `src/app/(public)/pricing/page.tsx` | NEW | The surface. Server component, no session read, no scan read, no `scanId` anywhere. Renders (1) one offer block whose rows are `offerTerms()`'s, each row's word through `copy()` and each row's value from the pin `offerTerms()` carries — the component formats no number of its own; (2) the three `PRICE_COPY_KEYS` sentences; (3) exactly one control that begins checkout, posting to BP-030's `createCheckoutSession({ origin: { kind: 'pricing' }, returnTo })`. Composed from registered components only (`Card`, `Btn`, `Divider` — `design/components.md`), holds no string literal a person reads, and asks for no address, account, password or field before the control. |
| `tests/app/pricing/pricing.test.tsx` | NEW | The suites below. |

## Interfaces

Consumes (verbatim from BP-031 `## Public interface`):
```ts
/** REQ-021 criterion 2's closed list, in the order every surface states it.
 *  Values are pins (BP-005); words are copy keys (BP-019, REQ-093). The list is
 *  derived once so criterion 4's "on the same terms" is a type, not a habit. */
export interface OfferTerms {
  priceKeys: typeof PRICE_COPY_KEYS               // from BP-030
  rows: readonly [
    { key: 'offer.cadence.page';        value: number },  // pages written per day
    { key: 'offer.cadence.measure';     value: 'weekly' },
    { key: 'offer.cadence.movement';    value: 'weekly' },
    { key: 'offer.veto.window';         value: number },  // default veto hours
  ]
  cancelKey: 'offer.cancel_self_service'
  startKey:  'offer.start'
}
export function offerTerms(): OfferTerms
```
Consumes (verbatim from BP-030 `## Public interface`):
```ts
/** Where the buyer came from. `scanId` is present only when a completed report
 *  exists for it; a scanless surface never fabricates one (BUILD.md §13). */
export type CheckoutOrigin =
  | { kind: 'report'; scanId: string }
  | { kind: 'pricing' }

export function createCheckoutSession(a: {
  origin: CheckoutOrigin
  returnTo: string                     // absolute ReachKit URL, allow-listed to NEXT_PUBLIC_APP_URL
}): Promise<
  | { ok: true; url: string; sessionId: string }
  | { ok: false; reason: 'origin_scan_incomplete' | 'return_to_not_ours' | 'vendor' }
>

/** The copy keys every price-bearing surface must render. Naming only — the
 *  sentences are the owner's and live in BP-019's registry (REQ-093). */
export const PRICE_COPY_KEYS: readonly ['price.amount', 'price.vat_included', 'price.interval']
```
Also consumes: BP-019's `copy()` (WO-041) and BP-018's registered components.
`offerAvailable()` is **not** consumed: it answers REQ-021 criterion 3 for the
report's offer, and this surface has no scan to ask about.

Exposes: no runtime interface — one route module. `PUBLIC_PATHS` already carries
`/pricing` (WO-003 writes that allow-list from BP-001's public route list); this
work order does not touch `src/middleware.ts`.

## Steps
1. Produce the preview artifact at the path in the display bullets above and hold
   in draft until it is signed off (constitution rule 7.3). This WO does not
   proceed to implementation before that.
2. Write the failing suites first.
3. Render the offer from `offerTerms()` by iterating its `rows` tuple — never a
   hand-written list — so criterion 4's "on the same terms" holds by
   construction and adding a row to `OfferTerms` renders it here without an edit.
4. Render the three `PRICE_COPY_KEYS` sentences through `copy()`. Pass no amount
   and format no currency: the amount is inside the owner's sentence.
5. Render exactly one control, posting `{ origin: { kind: 'pricing' }, returnTo }`.
   `returnTo` is this surface's own absolute URL, built from
   `NEXT_PUBLIC_APP_URL`; the route asks for nothing before the post.
6. Assert in the suite that the module reads no session and no scan.
