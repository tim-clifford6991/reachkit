# WO-118 — createCheckoutSession and CHECKOUT_PARAMS — what checkout asks, and nothing else

- Branch: wo/WO-118-create-checkout-session
- Estimate: ≤1 day

## Goal
Build the one Checkout Session the product opens, from an exported parameter
object that can be asserted field by field, and refuse a return address that is
not ours and an origin whose scan has not finished.

## File plan
> **Every path below is NEW.** No `src/` exists. Placement is anchored to
> `registry/structure.md` (`src/lib/account/**` is BP-017's) and BP-030's `code:`
> glob `src/lib/account/checkout/**`. Provisional against a repo with no code.

## Interfaces
Consumes (verbatim from BP-030's `## Public interface` and BP-005):
```ts
export const CHECKOUT_PARAMS: {
  mode: 'subscription'
  line_items: [{ price: string /* env STRIPE_PRICE_ID */; quantity: 1 }]
  billing_address_collection: 'required'      // REQ-022 c5
  tax_id_collection: { enabled: true }        // REQ-022 c6
  automatic_tax: { enabled: false }           // ADR-052
  customer_creation: 'always'
  phone_number_collection: { enabled: false } // REQ-020 c6
  custom_fields: []                           // REQ-020 c6
  allow_promotion_codes: false                // REQ-022 c3
  currency: 'eur'                             // REQ-022 c4
}
```
Exposes (verbatim from BP-030's `## Public interface`):
```ts
export type CheckoutOrigin =
  | { kind: 'report'; scanId: string }
  | { kind: 'pricing' }

export function createCheckoutSession(a: {
  origin: CheckoutOrigin
  returnTo: string                     // absolute ReachKit URL, allow-listed to NEXT_PUBLIC_APP_URL
}): Promise<
  | { ok: true; url: string; sessionId: string }
  | { ok: false; reason: 'origin_scan_incomplete' | 'return_to_not_ours' | 'vendor' }
>

export const PRICE_COPY_KEYS: readonly ['price.amount', 'price.vat_included', 'price.interval']
```

## Steps

2. Write `return-to.ts` and its refusal cases.
3. Write `origin.ts` against BP-012's `readCurrentReport()` scan status.
4. Write `session.ts`, wiring the three together plus one Stripe call.
5. Write `copy-keys.ts`.
6. Add the source-level no-VIES test.
