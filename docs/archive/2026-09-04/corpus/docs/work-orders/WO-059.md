# WO-059 — `ceilings.ts` — the 90-second deadline, the spend ceiling, and the one bounded `Ending` (ADR-021)

- Branch: wo/WO-059-ceilings
- Estimate: ≤1 day

## Goal
Guarantee that every free scan reaches exactly one `Ending`, that neither ceiling
is ever exceeded to finish outstanding work, and that a ceiling always produces a
report — with the two "obvious fixes" ADR-021 names each written as a test that
fails.

> **Read `decisions/ADR-021.md` before writing a line of this WO.** It is a
> landmine: raising the cap to finish the last call, and computing a partial
> score from the factors that were measured, both read as kindnesses and both
> break a promise a customer can be shown.

## Interfaces

Consumes: BP-007's `CostContext` (`capHit()`, `spentCents()`, `degraded()`) and
`withCostContext`; BP-005's `TIMING` and `CAPS.FREE_C`.

Exposes (verbatim from BP-023 `## Public interface`, `src/lib/scan/ceilings.ts`):

```ts
/** REQ-003's "bounded moment", made total. A free scan reaches exactly one. */
export type Ending =
  | { kind: 'report'; complete: true;  stoppedReason: 'complete' }
  | { kind: 'report'; complete: false; stoppedReason: 'time_ceiling' | 'spend_ceiling' }
  | { kind: 'no_report'; stoppedReason: 'failed' }

/** The deadline every stage and every multi-call step re-checks, exactly as
 *  BP-007's `capHit()` is re-checked between calls. */
export interface Bounds {
  expired(): boolean                 // now ≥ startedAt + TIMING.reportCeilingS
  remainingMs(): number
  capHit(): boolean                  // delegates to the CostContext, CAP_FREE
  stopNow(): 'time_ceiling' | 'spend_ceiling' | null
}
export function withFreeBounds<T>(
  a: { scanId: string; startedAt: Date },
  body: (b: Bounds) => Promise<T>
): Promise<{ result: T | null; ending: Ending }>
```

## Steps
1. Write the failing suites first, ADR-021's two prohibitions among them.
2. Implement `Bounds` over an injectable clock so the deadline tests need no real
   waiting; the clock is a parameter of the module, never read from a global
   inside the returned object's methods.
3. Implement `withFreeBounds`: run `body(bounds)`; when `stopNow()` fires,
   abandon outstanding work and return the `report` ending with the matching
   `stoppedReason`. Time is checked first when both fired in the same tick, since
   `TIMING.reportCeilingS` is the bound REQ-003 criterion 5 states absolutely.
4. Implement the `no_report / failed` ending per BP-023 decision 4: reached only
   when no ceiling was reached and every driver ended `unmeasured` with reason
   `undeterminable`. Any `not_attempted` anywhere means a ceiling acted, and a
   ceiling always yields a report.
5. Emit the one ending log line BP-023's NFR budget specifies: `stoppedReason`,
   elapsed ms, cents spent, whether the context degraded. Return none of it from
   `progress()` — no spend figure ever reaches a visitor.
6. Add the source assertions that no override exists.
