# WO-045 — The place module: PLACES, the one-account arbiter, and renderPlace()

- Branch: wo/WO-045-place-module
- Estimate: ≤1 day

## Goal
Create `src/lib/presentation/place/` — every place a value or a module can sit,
the one total function that gives a place holding nothing exactly one line in
ADR-011's fixed order, and the one renderer whose return type has no blank arm.

```ts
// ── src/lib/presentation/place/places.ts ─────────────────────────────────────
/** Every place a value or a module can sit, named `<surface>.<module>.<slot>`
 *  in lowercase-kebab segments. Total over the rendered surface: a place a
 *  screen renders that is not here fails the cold-start sweep by name. */
export type PlaceKey = string & { readonly __place: unique symbol }
export const PLACES: Readonly<Record<PlaceKey, PlaceSpec>>

export interface PlaceSpec {
  /** The one line this place carries when the customer has no presence yet.
   *  It must say both things REQ-091 criterion 2 requires: that they have no
   *  presence yet, and what will fill it. Its words are the owner's. */
  line: CopyKey
  /** What this place holds when it is not empty. `'module'` is a place with no
   *  value position at all — a list with no entries, a chart with no series —
   *  which REQ-091 criterion 2 reaches explicitly. */
  holds: 'value' | 'list' | 'series' | 'module'
  /** Where a sibling requirement already fixes this place's wording, the clause
   *  that fixes it. That fixed line is the place's one line; this node adds no
   *  second. A `fixedBy` place still has to satisfy criterion 2's two things —
   *  asserted, not assumed. */
  fixedBy?: string        // e.g. "REQ-041 c3", "REQ-043 c3"
}

// ── src/lib/presentation/place/account.ts ────────────────────────────────────
/** The closed set of reasons a place holds nothing. Adding a cause is an edit to
 *  this file, which is where the precedence lives — so a new cause cannot be
 *  added without meeting the ordering (ADR-011). Arms that carry a `line` are
 *  produced by another node and handed in, which is what keeps this module free
 *  of a dependency on BP-054 and the graph acyclic. */
export type Cause =
  | { tag: 'reachkit-stopped';    line: string }   // BP-054's stoppedWorkStatement
  | { tag: 'customer-instruction'; line: string }  // REQ-047 c5, via REQ-043 c5's node
  | { tag: 'named';               line: string }   // any cause a requirement names, REQ-043 c4
  | { tag: 'unrecognised' }                        // a cause no requirement names
  | { tag: 'supply-exhausted' }                    // REQ-043 c3, and only ever this
  | { tag: 'no-presence-yet' }                     // REQ-091 c2, the baseline account
export type CauseTag = Cause['tag']

export const CAUSE_PRECEDENCE: readonly CauseTag[] = [
  'reachkit-stopped', 'customer-instruction', 'named',
  'unrecognised', 'supply-exhausted', 'no-presence-yet',
] as const

/** Total over `Cause`. Returns exactly one line for a place holding nothing —
 *  REQ-091 criterion 2's "exactly one written line" and REQ-043 criterion 5's
 *  "exactly one account of itself" are the same function call. Ordering and the
 *  stopped-work invariant are ADR-011's. */
export function account(
  place: PlaceKey,
  causes: readonly Cause[]
): { line: string; cause: CauseTag }

// ── src/lib/presentation/place/render.ts ─────────────────────────────────────
/** BP-019's declared signature, verbatim. The line for a place holding nothing
 *  because the customer has no presence yet. */
export function emptyStateLine(place: PlaceKey): { line: string }

/** The one renderer for a place. A surface asks for a place, not for a value;
 *  the emptiness decision is made here and never at the call site. `value` of
 *  `null`, `[]`, or a `Measured` that is `unmeasured` is not a blank — it is a
 *  cause, and `account()` turns it into exactly one line. */
export type Place<T> =
  | { state: 'filled';    place: PlaceKey; value: T }
  | { state: 'accounted'; place: PlaceKey; line: string; cause: CauseTag }
export function renderPlace<T>(
  place: PlaceKey,
  value: T | readonly [] | null,
  causes?: readonly Cause[]
): Place<T>
```

## Steps
1. Create `places.ts`. Declare `PlaceSpec` exactly as above. Declare `PLACES` as
   an object literal ending `as const satisfies Record<string, PlaceSpec>` and
   freeze it, then derive `export type PlaceKey = keyof typeof PLACES`. See the
   rule 1.1 decision below on why the declared brand is not shipped.
2. Seed exactly these five places — names are internal (constitution §1's table),
   `line` values are the owner-owed keys WO-041 seeds, `fixedBy` strings are
   copied from BP-021's third `rests-on` row:
   | `PlaceKey` | `line` | `holds` | `fixedBy` |
   |---|---|---|---|
   | `overview.weekly-presence.chart` | `place.overview.weekly-presence.chart` | `series` | `REQ-041 c3` |
   | `overview.weekly-presence.week` | `place.overview.weekly-presence.week` | `value` | `REQ-065 c3` |
   | `overview.weekly-presence.partial-week` | `place.overview.weekly-presence.partial-week` | `value` | `REQ-065 c4` |
   | `calendar.date.page` | `place.calendar.date.page` | `module` | `REQ-043 c5` |
   | `report.first-page.rival` | `place.report.first-page.rival` | `value` | `REQ-010 c1` |
3. Create `account.ts`. Declare `Cause`, `CauseTag` and `CAUSE_PRECEDENCE`
   verbatim as above, in that order, in one file — ADR-011 point 6: "adding a
   cause puts the author in front of the ordering."
4. Implement `account(place, causes)`: walk `CAUSE_PRECEDENCE` in order and take
   the first tag present in `causes`. For an arm carrying a `line`, return that
   line unchanged — it was produced by the owning node and is not re-rendered
   here. For `unrecognised` return `copy('cause.unrecognised')`; for
   `supply-exhausted` return `copy('cause.supply-exhausted')`; for
   `no-presence-yet` return `copy(PLACES[place].line)`. With an empty `causes`
   array, return the `no-presence-yet` result — there is no path returning
   nothing (BP-021 `## Error & edge behavior`, fifth bullet).
5. Close the switch with an exhaustiveness check assigning the narrowed `Cause`
   to `never`, so a seventh arm added later does not compile until it is placed
   in the precedence.
6. Create `render.ts`. `emptyStateLine(place)` returns
   `{ line: copy(PLACES[place].line) }`. `renderPlace(place, value, causes)`
   returns the `accounted` arm — `account(place, causes ?? [])` spread into it —
   when `value` is `null`, is an empty array, is a `Measured` whose `kind` is
   `'unmeasured'`, or when `PLACES[place].holds === 'module'` and the value holds
   no entries and no series; otherwise the `filled` arm. Declare `Place<T>` with
   exactly the two arms above: no `blank`, no `hidden`, no `placeholder`, no
   `spinner`, no `undefined` (BP-021 `## Error & edge behavior`, first two
   bullets — these renderings are absent from the return type, not tested for).
7. Create `index.ts` re-exporting exactly the symbols in `## Interfaces`.
8. Write the three test files. Watch each fail before its source file exists.

## Out of scope
- The cold-start fixture and the pipeline-completion assertion — WO-046.
- The cold-start route sweep and the provenance assertion — WO-047.
- `stoppedWorkStatement`, `dayAccount` and the `reachkit-stopped` line's content
  — BP-054's, WO-048 and WO-049. This module accepts that arm's line already
  rendered and never produces it.
- The wording of any line. Every line is a `CopyKey` whose value is the owner's.
- Adding a seventh `Cause`. The union is closed; a new cause is a later edit that
  must place itself in `CAUSE_PRECEDENCE` (ADR-011 point 6).

## Decision taken under rule 1.1
BP-021's interface block declares `PlaceKey` two ways: as a branded opaque string
(`string & { readonly __place: unique symbol }`) in the interface, and in
`## Error & edge behavior` as "a `PlaceKey` union generated from the registry's
own literal", which also states "a `PlaceKey` cannot be constructed from an
arbitrary string". A branded string does not give the second property — any
string can be cast into a brand — and the two declarations cannot both hold.
**Chosen: `PlaceKey = keyof typeof PLACES`**, the union, because it is the form
that delivers the property the error section makes load-bearing and the form the
sweep's "fails by name" behaviour needs. The brand is not shipped. This is
reported to the architect as an interface inconsistency in BP-021 and is not
fixed here — a planner does not edit a blueprint. Cost of reversing: one type
alias in `places.ts`; no consumer changes, because every consumer receives a
`PlaceKey` rather than constructing one.
