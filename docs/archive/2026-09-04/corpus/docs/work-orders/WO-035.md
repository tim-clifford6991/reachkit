# WO-035 — Charts, part 1 — GrowthLine, PresenceBars, RivalSparkline

- Branch: wo/WO-035-charts-1
- Estimate: ≤1 day
- Preview: sdlc-factory/docs/design/previews/WO-035.html
- Signed-off: <date>

## Goal
Ship three of the five inline-SVG charts, with two series colours, direct labels
on every mark, and a rival series that cannot be given an alarm tone.

## Provenance of this file plan
**This repository holds no `src/`.** Every path is NEW under BP-018's `code:`
glob `src/ui/**`.

## File plan
| File | New/Modify | Change |
|---|---|---|
| `src/ui/charts/chart-primitives.ts` | NEW | The shared axis, gridline, endpoint-dot and tooltip primitives `BUILD.md` §2.4 fixes: one axis per chart, 2–2.5px lines, 3.5–5px endpoint dots with a surface-coloured ring, faint gridlines at 2–3 values, a fixed-position ink-on-bg mono tooltip. Inline SVG with a hand-sized viewBox; no chart library is imported. |
| `src/ui/charts/series.ts` | NEW | The series type. `SeriesKind = 'you' \| 'rival'` mapping to `--chart-you` and `--chart-rival` and to nothing else. **`Tone` is not accepted by the rival series props at all** — the rival props type has no tone field, so BP-018's rule cannot be broken by a prop. |
| `src/ui/charts/GrowthLine.tsx` | NEW | Overview's growth line. Every point direct-labelled with name and value; values render through `.num`. |
| `src/ui/charts/PresenceBars.tsx` | NEW | The report's presence bars. Every bar direct-labelled; no legend-only mode. |
| `src/ui/charts/RivalSparkline.tsx` | NEW | Overview's rival-gap sparklines. Rival series is `--chart-rival`, neutral, with no way to make it red. |
| `src/ui/charts/index.ts` | NEW | Barrel for the closed five. WO-036 appends, which is why the two are sequenced. |
| `tests/ui/charts-1.test.tsx` | NEW | The tests below. |

## Steps
1. Write `series.ts` so the rival props type has no tone field.
2. Write the primitives.
3. Write the three charts.
4. Write the tests; watch the "a rival series cannot be given a tone" test fail
   first by adding the field, then remove it.
