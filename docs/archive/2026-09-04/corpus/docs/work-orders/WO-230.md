# WO-230 — The hosted page — one typographic render, canonical on the customer's domain, FAQPage from data, zero client JavaScript

- Branch: wo/WO-230-hosted-page-render
- Estimate: ≤1 day
- Preview: sdlc-factory/docs/design/previews/WO-230.html
- Signed-off: <date>

## Goal
Ship the one hosted page render and the head it emits — canonical on the customer's own domain, `FAQPage` only where the data is present, robots forced off on the preview — with the whole page content in the HTML at first byte.

> `code:` globs, and is provisional against a repo with no code: if the

| `src/app/(hosted)/[slug]/page.tsx` | NEW | The one page render and the head it emits. `<link rel="canonical">` at `https://content.{sites.domain}/{slug}` — **always the customer's domain, never a ReachKit address, and never a self-canonical on the preview host**. `FAQPage` JSON-LD emitted **only** where `drafts.meta.faq` is present and non-empty; an absent or empty section emits no markup at all rather than an empty `FAQPage`. ## Interfaces

**Consumes**

- `resolveHost`, `HostDisposition`, `tags` — `src/app/(hosted)/resolve-host.ts` (WO-229).
- BP-018's theme tokens and registered components — `src/ui/theme.css`, `src/ui/components/**`. **Named tokens and registered components only** (rule 7.3).
- `copy()` — BP-019, `src/lib/presentation/`. Every string except the page body.
- `drafts.body_md` and `drafts.meta` — BP-002 and BP-014. `drafts.meta.faq` is the `rests-on` above.

**Exposes** — copied exactly from BP-047's `## Public interface`:

```ts
GET  https://content.{customer-domain}/{slug}       one published page
GET  https://{slug}.reachkit.app/                   the same render; noindex forever (ADR-002)
```

**Generated prose is allowed here and nowhere else.** The page body is the one
place the product renders text no copy key holds (REQ-093 criterion 2); every
other string on the surface is `copy()`. This is the exception rule 7.3's "long
LLM-generated text in the UI is a defect" is written against, and it is stated in
an approved requirement.

**`FAQPage` is emitted from `drafts.meta.faq`, not from parsing markdown**
(BP-047 decision 2). A render-time heading heuristic that is wrong emits schema
claiming a Q&A that is not there — a structured false statement on the customer's
own domain. If `drafts.meta.faq` turns out unavailable, the fallback is a
generation-side change in BP-014, **not** a parser here: the implementer stops and
logs `failed — next: raise the rests-on with BP-014` rather than writing one.

**No JavaScript is required to read the page**, because REQ-062 criterion 1
verifies it as a crawler that runs no scripts (WO-234). A component that needs
client JavaScript to render page text is a defect on this surface, not a
preference.

## Steps
1. Read ADR-002 before writing the preview head. The `noindex` is load-bearing and its removal reads as a bug fix.
2. Create `layout.tsx` from BP-018's tokens and registered components only. Introduce no new component and no raw colour or size.
3. Create `[slug]/page.tsx`. Take `indexable` from the disposition; do not recompute it and do not read a setting.
4. Emit the canonical from `sites.domain` always. On the preview host emit no self-canonical.
5. Emit `FAQPage` only from `drafts.meta.faq`, non-empty. Emit nothing where it is absent.
6. Require `delivery_state='delivered'`, hosted kind and null `unpublished_at` before rendering anything.
7. Read the page under the two cache tags from WO-229.
8. Write the "the preview carries noindex on both the tag and the header and no setting clears it" test first and watch it fail against a render that reads indexability from a column (constitution §8).
