```ts
// src/lib/market/rivalset/index.ts — the invariant, shared with BP-056
export type RivalOrigin = 'suggested' | 'typed'
export interface RivalEntry { domain: string; origin: RivalOrigin }
export type RivalSet = readonly RivalEntry[]              // length ≤ BATTERY.COMPETITORS_MAX
export type RivalRejection =
  | 'not_a_domain' | 'does_not_resolve' | 'own_domain' | 'already_present' | 'set_full'

export function normaliseRivalInput(input: string): string | null   // eTLD+1 or null
export function addRival(set: RivalSet, a: {
  input: string; origin: RivalOrigin; ownDomain: string
}): Promise<{ ok: true; set: RivalSet } | { ok: false; because: RivalRejection; set: RivalSet }>
export function removeRival(set: RivalSet, domain: string): RivalSet
export function clearSuggested(set: RivalSet): RivalSet             // keeps every 'typed' entry
```

## Steps
1. `normaliseRivalInput` delegates to `registrableDomain` (WO-077). It mints no second
   normalisation: two eTLD+1 implementations in one product is a rule 7.1 conflict.
2. `addRival` evaluates in this order and returns **the original set unchanged** on every
   rejection arm — a rejected value consumes none of the five (REQ-026 criterion 8):
   - `normaliseRivalInput(input) === null` ⇒ `'not_a_domain'`.
   - `isOwnDomain(normalised, ownDomain)` ⇒ `'own_domain'`. This matches on `www.` and on the
     `content.` publishing subdomain, so self-comparison is impossible.
   - the normalised domain is already in the set ⇒ `'already_present'`. Matching is on the
     normalised value, so "however it is typed" holds.
   - `set.length >= BATTERY.COMPETITORS_MAX` ⇒ `'set_full'`. **Never truncate**: the limit is
     stated, not silently enforced, so the surface has something to say.
   - `await resolvesInDns(normalised) === false` ⇒ `'does_not_resolve'`.
   On success, append `{ domain: normalised, origin }`.
3. Reachability is `resolvesInDns()` and **nothing more**. Make no fetch against a rival
   domain: a rival whose site is new, thin, unbuilt or blocking our fetcher is accepted.
   Bound the lookup at 2 s (BP-034's `## NFR budget`) and treat a timeout as
   `'does_not_resolve'` — it is the only I/O in this module.
4. `removeRival` returns a new set without the entry whose `domain` matches after
   normalisation; removing an absent domain returns the set unchanged and throws nothing.
5. `clearSuggested` keeps every `origin: 'typed'` entry in order and drops every
   `'suggested'` one. `origin` is set once at the moment of adding and is never recomputed
   (BP-034 decision 3).
6. Every function returns a new array; none mutates its argument.
7. Emit the observability field BP-034 names: every rejection reason.
8. Write the tests; watch each fail first.
