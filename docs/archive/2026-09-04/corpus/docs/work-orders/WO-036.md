# WO-036 — Charts, part 2 — AiDotMatrixChart and WeekStrip, and the closed inventory

- Branch: wo/WO-036-charts-2
- Estimate: ≤1 day
- Preview: sdlc-factory/docs/design/previews/WO-036.html
- Signed-off: <date>

## Goal
Complete the closed five-chart inventory and make the closure testable, so a
sixth chart form cannot ship without a design artifact.

## Provenance of this file plan
**This repository holds no `src/`.** Every path is NEW under BP-018's `code:`
glob `src/ui/**`, except the chart barrel this work order appends to. Sequenced
after WO-035 for that reason, and after WO-033 because `AiDotMatrixChart` is the
chart form of the component WO-033 shipped and must share its cell contract
rather than mint a second one.

## File plan
| File | New/Modify | Change |
|---|---|---|
| `src/ui/charts/AiDotMatrixChart.tsx` | NEW | The report-and-Overview dot matrix as a chart: axes, tooltip and the shared primitives, over the **same** cell contract `AiDotMatrix` (WO-033) declares — `AiDotMatrixRow`, `AiDotMatrixCell` and `AiDotMatrixCellState`, imported by name, never re-declared, so one capability has one shape. That contract is three-state (`cited · not-cited · muted`) with a row identity as of 2026-08-31; this chart renders the same three and adds only the dashed goal dots `design/components.md` lists for it. Every dot direct-labelled. |
| `src/ui/charts/WeekStrip.tsx` | NEW | Overview's 7-day week strip. Each day direct-labelled with its date, rendered through `.num`; a day with nothing measured renders as an explicitly empty mark the caller labels, never as a gap. |
| `src/ui/charts/index.ts` | MODIFY | Appends the two; the inventory is now exactly five. |
| `tests/ui/charts-2.test.tsx` | NEW | The tests below, including the closure test. |

## Interfaces
Exposes (verbatim from BP-018 `## Public interface`, completing the line):
```ts
export { GrowthLine, PresenceBars, AiDotMatrixChart, RivalSparkline, WeekStrip } from './charts'
```
Consumes: `chart-primitives.ts` and `series.ts` (WO-035), `AiDotMatrix`'s cell
type (WO-033), `.num` (WO-030).

## Steps
1. Write `AiDotMatrixChart` over WO-033's cell type.
2. Write `WeekStrip`.
3. Append to the barrel; assert the set is five.
4. Write the tests; watch the closure test fail first by exporting a sixth chart.
