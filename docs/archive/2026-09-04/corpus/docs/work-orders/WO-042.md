# WO-042 — explain(): a number reaches a sentence only as a Measured<T>, carrying its scan date

- Branch: wo/WO-042-explain
- Estimate: ≤1 day

## Goal
Add `explain()` to `src/lib/presentation/copy/` so that the only way a number
reaches a product sentence is as a `Measured<T>` whose scan date travels with it,
and a raw number is a type error at the call site.

## File plan
| File | New/Modify | Change |
|---|---|---|
| `src/lib/presentation/copy/explain.ts` | **NEW** | The `HasMeasuredSlot<K>`, `MeasuredSlotOf<K>` and `ExplainKey` type computations over `COPY_META`'s literal types, and the `explain()` function. Renders each `'measured'` slot through BP-019's `renderMeasured`, returns the substituted text, the scan dates it used, and whether any slot rendered as a dash. |
| `src/lib/presentation/copy/index.ts` | **Modify** (created by WO-041) | Re-export `explain` and the types `ExplainKey`, `MeasuredSlotOf`. |
| `tests/presentation/copy/explain.test.ts` | **NEW** | TST for the four properties criterion 4 states, including the `@ts-expect-error` fixtures that carry the type-level half. |

## Interfaces
**Consumes:**
- From WO-041, in this same module: `COPY`, `COPY_META`, `CopyKey`, `CopyMeta`,
  `OWNER_OWED`.
- From BP-010, type-only (BP-020 `## Dependencies on other BP nodes`: "**BP-010**
  — the `Measured<T>` type, type-only, for `explain()`"), verbatim from BP-010's
  `## Public interface`:
```ts
export type Measured<T> =
  | { kind: 'measured';   value: T; at: Date }
  | { kind: 'zero';       value: T; at: Date }           // read it; it contained none
  | { kind: 'unmeasured'; reason: 'undeterminable' | 'not_attempted'; at: Date }
```
- From BP-019, verbatim from BP-019's `## Public interface`:
```ts
export function renderMeasured<T>(m: Measured<T>, o: {
  format: (v: T) => string
  unmeasuredLine: CopyKey        // differs by reason: undeterminable vs not_attempted
}): { text: string; isDash: boolean; line?: string }
```

**Exposes** (verbatim from BP-020 `## Public interface`):
```ts
// ── src/lib/presentation/copy/copy.ts ────────────────────────────────────────
/** REQ-093 criterion 4. The only way a number reaches a sentence. Each slot is
 *  a `Measured<T>` — never a raw number — so a value that was estimated,
 *  recomputed for display or produced by a model is not of the argument's type,
 *  and the scan date travels with it. There is no reader, session or persona
 *  parameter, so the words cannot change with who is reading. */
export type ExplainKey = { [K in CopyKey]: HasMeasuredSlot<K> extends true ? K : never }[CopyKey]
export function explain<K extends ExplainKey>(
  key: K,
  slots: { [S in MeasuredSlotOf<K>]: { value: Measured<unknown>; format: (v: never) => string } },
  vars?: Record<string, string>
): {
  text: string
  /** Every scan date behind the values in this sentence. Empty is impossible:
   *  `ExplainKey` has at least one measured slot. */
  measuredAt: readonly Date[]
  /** True when any slot rendered as "—". The sentence still renders. */
  hasUnmeasured: boolean
}
```

## Steps
1. Create `explain.ts`. Compute the two helper types from `COPY_META`'s literal
   types (WO-041 step 1 declares `COPY_META` with `satisfies`, which is what
   makes this computable):
   `type MeasuredSlotOf<K extends CopyKey> = { [S in keyof (typeof COPY_META)[K]['slots']]: (typeof COPY_META)[K]['slots'][S] extends 'measured' ? S : never }[keyof (typeof COPY_META)[K]['slots']]`
   and `type HasMeasuredSlot<K extends CopyKey> = [MeasuredSlotOf<K>] extends [never] ? false : true`.
   Export `ExplainKey` exactly as the interface block declares it.
2. Implement `explain()`: for each measured slot, call `renderMeasured(slot.value,
   { format: slot.format, unmeasuredLine })` where `unmeasuredLine` is chosen by
   the `Measured`'s `reason` — REQ-004's trichotomy is BP-019's and is **not
   re-implemented here** (BP-020 `## Error & edge behavior`, fifth bullet).
   Collect `at` from every slot into `measuredAt`; set `hasUnmeasured` true when
   any `renderMeasured` result has `isDash` true. Substitute the non-measured
   slots from `vars`. The sentence still renders when a slot is unmeasured.
3. The function takes no session, reader or persona parameter and reads no
   module-level mutable state, per the interface comment above.
4. `explain()` on an owner-owed key throws the same way `copy()` does (WO-041
   step 3) — one guard, called from both, living in `copy.ts` and imported here;
   do not write a second guard (rule 7.1).
5. Add the two exports to `index.ts`.
6. Write `tests/presentation/copy/explain.test.ts`. Watch it fail before
   `explain.ts` exists.

## Test plan

Discriminates: widening the slot parameter to `unknown` makes all three compile and the test fails. |
| 4. Discriminates: dropping `at` collection returns `[]` and fails. |
| 4. | 4. (same, verbatim as above) | `explain.test.ts` → **"the words do not change with who is reading"**: `explain.length === 3` and no argument position accepts a session, reader or persona; two invocations with identical arguments return byte-identical `text`. | 5. "Given the product's language models are unavailable, when anyone opens a ReachKit surface, then every word in the product's own voice renders unchanged, and page content already written still renders from what was stored." | `explain.test.ts` → **"explain renders with every model unavailable"**: with every export of `src/lib/llm/` replaced by a throwing stub, a sentence with a measured slot renders unchanged. |
