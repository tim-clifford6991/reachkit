# WO-014 — The seven JobIds, the kill switch and its exact scope

- Branch: wo/WO-014-kill-switch
- Estimate: ≤1 day

## Goal
Close the job-id union at exactly seven members and make the kill switch stop
three of them — before any spend and before any write — and stop nothing else.

## Provenance of this file plan
**This repository holds no `src/`.** Every path is NEW under BP-003's `code:`
glob `src/jobs/**`.

## File plan
| File | New/Modify | Change |
|---|---|---|
| `src/jobs/types.ts` | NEW | The `JobId` union, exactly BP-003's seven members with their trigger comments transcribed, plus `JobDefinition` and the `Outcome` type carrying `degraded` and the step that degraded. |
| `src/jobs/kill-switch.ts` | NEW | `killSwitchEngaged()` reading `KILL_SWITCH` through `env`, and `KILL_SWITCH_SCOPE`, the closed set `['scan/run', 'draft/generate', 'publish/execute']`. A guard helper a job definition applies before its first spend and before its first write. |
| `tests/jobs/kill-switch.test.ts` | NEW | The tests below. |

## Interfaces
Exposes (verbatim from BP-003 `## Public interface`):
```ts
// each job, exactly these seven ids — adding one is a change to this node
type JobId =
  | 'scan/run'          // on demand; tier is a parameter (free | deep | weekly)
  | 'draft/generate'    // daily, evening, per site, in the site's time zone
  | 'publish/execute'   // on approval or on window expiry
  | 'publish/verify'    // +24h after a publish
  | 'weekly/refresh'    // hourly tick, due per site-local Monday (ADR-060)
  | 'lead/nurture'      // event plus delay: 24h / 72h / 168h
  | 'account/maintenance'

export function killSwitchEngaged(): boolean   // reads KILL_SWITCH via BP-005
```
Consumes: `env` (BP-005), `MAINTENANCE_TICK_MINUTES` (BP-005 `constants.ts`).

## Steps
1. Write the union with its comments transcribed verbatim.
2. Write the switch and its scope set.
3. Write the guard so it runs before the first spend and before the first write.
4. Write the tests; watch the "verify and maintenance are not stopped" test fail
   first by widening the scope set to all seven.
