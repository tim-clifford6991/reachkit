# Doctrine changelog

One line per version; **migration** names the corpus rewrite that ships
with a grammar change (CLAUDE.md's three-part rule), and **none (stated)**
records — in the tree, not just in git — why a version rung ships without
one.

| 0.13.2 | **Lean mode** (owner ruling 2026-09-04, measured: ~70% of a work order's elapsed time was validate + regress + audit, and each of those dispatches re-read the corpus — 41M cache-read tokens for one order; under a five-hour window that is the schedule). Four changes. **Gates per wave, not per order**: an order proves its own tests and typecheck, merges into `wave/W<n>`, and stops; at `/wave close` one validator pass over the merged result writes ONE `## TST-###` section carrying `Validates: WO-…, WO-…`, one regression sweep covers the union of their impact, and one librarian audit sets `done` for every order in the row. The parser mints a real `validates` edge per id on that line, so `done-without-validation` needs no special case and `tst-without-regression` finds an order's section through the edge rather than in its own body. **Risk-scoped mutation**: `risk: high|normal` in front-matter, set by the planner from the seams the project's charter names (§8 states the test — money, access control, data leaving the system, a third-party callback, a publishing state machine — and names the first live project's five as the worked example, not as doctrine); the validator mutation-tests `high` only; `high-risk-without-mutation` (**error**) refuses `done` without a `Mutation:` line, and reports an off-vocabulary value rather than reading it as normal. **Context packs** (new rule 4.5): every dispatch carries the order, the artifacts its own edges name one hop plus those blueprints' requirements, and its file-plan files — built by `factory-console pack WO-###`, with "read nothing beyond the pack unless a test fails" in the prompt and the pack's size on the order's `## Log`. **Rule 2.6 gains a floor**: a work order is a screen, or a capability with its API, and the planner merges anything smaller at wave proposal. Unchanged on purpose: rule 7.3's sheets before UI, the copy and component registry gates, and the main fast-forward at wave close | `0.13.2-a-lean-gates` (stated no-op — `risk:` absent already means normal, and backfilling it into every order would be a corpus-wide diff asserting an assessment no script can make; it counts and reports instead. | 0.13.0 | **The preview sign-off happens on a published page** (rule 7.3, rewritten). A preview becomes two things: the **sheet** — `design/previews/WO-###.html`, which stays in the corpus and is the record — and the **page**, that same sheet published as an artifact, which is the owner's door. The design-guardian writes and reviews the sheet, publishes it to the same file path every revision (stable URL, incrementing version), and records the pair in exactly two places: one `preview — design-guardian — v<n> — <url>` line in the work order's `## Log` (a sixth log form, and the only line there a checker reads) and the new `Preview` cell of every components.md row the sheet registers. The sign-off is the owner's word **on that page** — a comment addressed to Claude, or a ruling in the session naming the URL — and the **librarian** reads it back and writes `Signed-off:`, not the guardian: §4 gives it statuses, so it gains sign-offs and the Artifact tool to read comments with, and the standing rule that silence is not a sign-off. Born from the measured failure: the owner had to open an HTML file on the machine that ran the agent. One checker rule, `preview-without-url` (warn, front-matter only) — a `ui: yes` work order at `approved` or `done` whose log records no published page. The guard's ownership table gains design-guardian on `work-orders/`, closing a gap open since its 0.11.0 UI-fit pass began writing `REVIEW(placement)` lines there | `0.13.0-a-preview-page` (widens components.md with the `Preview` column, refusing a ragged table; names the `ui: yes` work orders already in implementation with no published preview and writes nothing into them — a URL is a value rule 1.2 forbids inventing, so the gap stands as a checker finding rather than a fabricated sign-off) |
