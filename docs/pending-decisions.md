written here the day they are made — one line each, in `DECISIONS.md`'s own format
(`YYYY-MM-DD  ruling — source`) — and moved into `DECISIONS.md` by the next docs batch, which
empties this file. A line here is binding already; it is only not yet in the append-only record.
