2026-10-24  **AI answer marks** (ux ruling E7, owner-delegated, #1747, #1963): an answer that was shown but links and names no one (answered, citedDomains: [], not named) is marked Names no one. It is not 'Mentions someone else' and not 'No answer'. It still counts as an answer (it raises m) and is a miss for the site. Its legend item is drawn only when at least one row carries the mark, so the AppAI board's four-item legend is unchanged in the usual case. Mark: grey (text-base-content/70) with lucide CircleDashed. The same rule holds for an opportunity target's engine standing, the calendar's why-row and the draft-ready mail, where such an engine reads "nobody", never "other sites". Target facts stored before this ruling keep their `names_others`.
