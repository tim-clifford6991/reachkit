2026-11-06  **A first deep pass that failed is re-run once the same day** (owner, #2430). The maintenance tick that re-measures a pass a ceiling stopped (#855) also re-measures a site whose only ended deep pass is its first and ended `failed`, within `TIMING.deepPassBackstopH` of setup, as a #837 re-measure under `REMEASURE.perDay` and `DAILY_SITE_C`, keyed on the failed pass (`scans_one_remeasure_per_pass`). A second failure, a weekly pass or any later pass is not re-run by this rule. The cost is one deep pass, only on a real failure.
