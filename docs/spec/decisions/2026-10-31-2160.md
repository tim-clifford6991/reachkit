2026-10-31  **Drafts publish on autopilot: a stopped page that passes today's rules enters review by itself, at 0¢** (owner O7, #2160). `needs_attention` is only for a cause that is critical for the customer. It amends the state machine's exit from `needs_attention`.

1. The system takes the edge `needs_attention → in_review` as `{system, draft/recheck}` when today's hard rules pass on the stored page. The edge keeps `never_entered_review` and `draft_passed_hard_rules`. `customer_initiated` stays on `needs_attention → generating` and on put-back.
2. The re-check runs at the start of each site's daily run, before the day's write. It makes no model call and no vendor call. A candidate:
   - never entered review;
   - was stopped by the rules at generation;
   - carries no edit of the customer's;
   - has a body.

   The newest pack goes first. The first that passes takes the date through `enterReview`, with the veto window, the veto link and the draft-ready mail.
3. OR1 (default): a rescued page takes the next free publish date, ahead of this week's plan.
4. OR2 (default): a page that still fails is retired at 0¢ (`needs_attention → skipped`), keeping its topic's rest (#2162). No paid fix call is built.
5. OR3 (default): only a page whose pack is at most `TOPIC_REST_DAYS` (28) old is re-checked.
6. OR4 (seo-master, answered no): a promise figure never goes in a non-offering title. A page whose title carries one is held: it stays `needs_attention` until a clean stored title is picked (#2161), or it is retired.
