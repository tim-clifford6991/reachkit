2026-11-24  **An interrupted write is stopped and its date freed like any stopped page** (owner, #2722 rulings 98.2 and 99.1; #3430). A `generating` row that no run is still writing is moved to `needs_attention` at 0¢, and its date is released; while that date is still ahead its day's recorded ending is cleared, so the next tick writes it. It is no longer rewritten automatically. The customer's restart is the one path that rewrites the same row. The move-back of earlier automatic rewrites to their planned date ends. `lines.areas.src/lib/generate` and `lines.areas.src/lib/publish` in `scripts/budgets.json` fall to what is left.
