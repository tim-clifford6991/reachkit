2026-11-01  **The plain-words count is measured against the pull request's base, and no number is stored** (architect plan on #2212, #2222). This replaces only the "How it is checked" paragraph of `2026-10-31-2145.md`. Owner O6 and its rules 1 to 12 are unchanged: a count may fall and never rise.

How it is checked. `scripts/lib/plain-words.mjs` is still the one parser, and `plainWordsFindings` in `scripts/lib/budgets.mjs` compares each count at the base with the same count at the head. `audit` (`scripts/hygiene.mjs`) counts each key file the pull request touches at `HEAD^1` and in the tree. `tests/ui/design/strategy.test.ts` counts each board the pull request touches in the same way, because `audit` runs without the board parser. The base always holds the last merged count, so a gain is kept as soon as it merges. A new key file or board has no ceiling yet. A run with no base, scheduled or on the box, skips the rule. Neither `scripts/budgets.json` nor `docs/design/parity/baseline.json` holds a `plainWords` number, and `scripts/copy/apply.mjs` writes neither. Exempt files and boards (rule 12) and the retired names stay as `2026-10-31-2145.md` sets them.
