2026-11-01  **The landing story card is built as its board draws it, and the board's empty slot and second Live mark are corrected** (owner, #2231). Context: on 2026-11-01 the owner said the hero visualisation "is lacking fullness, more icons, improved spacing etc to look like a complete component". ux-designer's review, carried on #2231, found that the shipped card (#2198) had dropped what boards PubLanding and PubLandingPhone already draw. The board puts node, title and a 268px bordered picture card side by side; the code put title and picture in one narrow column, so about 60% of the card was empty at 1280. The board's node is solid, 34px, with a 20px icon, aligned with its title on a 2px tinted line; the code's was a faint 32px node with a 16px icon, centred on the whole frame about 40px below its title. The board draws Live as a soft pill; the code drew it solid. The empty slot was `border-base-300` on a base-200 well, 1.06:1 in light, so it did not show. Under the parity rule (owner, 2026-10-20: shipped UI matches the canvas 1:1) the code moves to the board. Decision: two board edits, both of which correct the board itself. First, frame 1's dashed empty slot changes from `#c4c6dc` to `#8f909a` (about ink at 50%, roughly 3.2:1 on white), because the old colour is under the 3:1 that WCAG 2.2 1.4.11 Non-text Contrast asks of a graphic the story depends on. The code draws it as `border-base-content/50` on base-100: 3.18:1 light, 4.28:1 dark. Second, the CircleCheck in frame 3's second page band is removed, because it was a second "Live" mark; the band keeps its page icon. The board's structure (the `.sbrow` grid, the nodes, the line, the caption) stays. Headline, subline, story order and words per frame stay as `2026-10-31-2174.md` ruled (3, 2, 4 and 3), and no copy key changes. Consequences: both landing boards' `sha256` change in `docs/design/parity/baseline.json`. `missing` stays 0, `plainWords` stays 22, and `components` stays 43, because the board and the page each lose the same one CircleCheck. The header strip, engine marks, more research tiles and a three-state week (review §5 items 4 and 5) need an owner ruling and are #2232.
