2026-10-31  **A meta description never stops or warns on a page** (owner R-A, #2136; amends D51 and *How the title rules are carried out*: "a meta description is never a reason to block or warn"). Code fits the description the writer returns. One at or under 155 characters is kept as written. A longer one keeps the whole sentences that fit if they come to 120 characters or more, and is otherwise cut at the last word boundary at or under 155. No word is added. Its length is no longer part of the `title` check, and a short one publishes. The check asks only that a description is present. The writer is still asked for 120 to 155 characters.

2026-10-31  **A cut meta description ends on a complete thought** (owner R-A, #2136, applied in #2180). A description over 155 characters keeps the longest run of whole sentences that fits, however short; 120 is the writer's target, not a floor. Where no whole sentence fits, it is cut at the last clause boundary that fits where that keeps at least half the 155 (78 characters), so an early comma ("In 2026, …") is no cut; otherwise at the last word, and never ends on a function word of the page's language (every language's, where it is unknown). A cut ends with a full stop, the only character code adds.
