2026-11-01  **The landing's example report is ReachKit's own** (owner, #2265: *"swap podia for our own report"*). This amends 2026-11-01-2246: "the podia.com proof row" becomes ReachKit's own report row. It also replaces the podia.com example in 2026-10-19-1581 and 2026-10-20-1716. The reason comes from trust-compliance: featuring a third-party brand on the landing without its consent is a UWG/Lanham risk. The example report comes only from an approved list in `src/app/(public)/_how/examples.ts`. Today that list holds only `reachkit.app`. A customer who consents can be added to it later, and the list is the only way to add one. The row is drawn only while reachkit.app's free report is listed with a stored score. It shows ReachKit's own mark, "We run ReachKit on reachkit.app" and "See its free report", and links to `/scan/reachkit.app`. Until the owner decides, the landing shows no score number. The score is still passed to `landing.hero.proof.report`, so the key alone can show it again. `/about`'s report card says "Our own free report". podia.com's report stays in the gallery.
