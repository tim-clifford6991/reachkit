2026-11-24  **One "enough sources" number per page type** (owner, #2722 ruling 100.3; #3431). Every "enough sources" decision reads the page type's `sources` through `sourcesNeed`: the pack's `outside_sources`, the research top-up, the brief and the battery. An update's number is 0 unless it fell from a type with sources, so a refresh of a live how-to or Q&A no longer marks `outside_sources` short; it never stopped a page. `lines.areas.src/lib/generate` in `scripts/budgets.json` falls to what is left.
