- **Cut:** the lead's "Up to 7 pages a week, new or updated. Never filler."; the four-tile numbers strip; "Runs by itself"; the page thumbnails; the New/Update legend; the dots legend over Live pages; "4 of 12 live pages"; and the search phrase repeated inside each live row's sentence.

The wording exceptions, and why each holds:

1. **The stopped day's line** reads "Stopped by you. Other days are not affected." The board's "on Mon 19" is not added: the row already starts with its own date, and the stop's own date is not a stored fact of the day.
2. **The skipped day's line** reads "Nothing worth writing for this day, so no page." The board's "today" holds only on the current day's row. Every other day's row would read wrong.
3. **The note on the live-page number** ("On live pages the number is this week's Google position.") goes. No row draws a number now, so it would explain nothing.
4. **The board's "A page that didn't pass our checks" state** is dropped from the board's state strip only. The product still draws a set-aside page as "Set aside" (owner O7, #2164). That rule is unchanged.
5. **The stage filter** stays above the week. Neither board draws it; it is REQ-043 (SPEC §7), and a board yields to a SPEC line.
