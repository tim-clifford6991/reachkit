2026-11-08  **The first load's stylesheet and scripts** (owner, #2487, option A). The one render-blocking stylesheet, on the public pages and in the app alike, is held to its size as `next build` measures it plus about 2%: `WEB_VITALS_BUDGET.MAIN_CSS_KB` is 250 KB uncompressed, for a measured 245.1 KB. The ruling named 240 against an estimate of 235 KB and asked for a re-measure from `next build`. It got there from 339 KB by having Tailwind scan only `src/app` and `src/ui`, with daisyUI given the list of components in use. Typography stays, and there is still one sheet. The draft editor loads only when its edit arm opens. Overview's charts are not lazy-loaded, because they draw on the first paint. Instead `/app` and the draft view are each held to a script budget.
