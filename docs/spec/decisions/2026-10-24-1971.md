2026-10-24  **A score shows its range, never a confidence word** (ux-designer E9, owner-delegated, #1931, #1971): the free report and Overview show a score's estimate as its range only ("somewhere between {low} and {high}"), never a confidence word; the stored confidence decides only how wide the range is. Amends §2 2026-10-15 (2)'s display clause and §0's Visibility Score sentence. The stored `verdict.estimate` (low, high, confidence) and the rough/close rule are unchanged, so no stored scan is re-scored. *Why* (`/root/projects/reports/ux-parity-live-2026-10-24.md` §7): the board PubReport (canvas V19/V22, signed off 2026-10-19) draws the range alone; "close" is ambiguous for a second-language reader, and "rough estimate" on the first number a stranger sees reads as "this tool is not sure", while the range's width already says how sure.
