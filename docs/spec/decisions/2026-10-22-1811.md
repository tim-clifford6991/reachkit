2026-10-22  **The first page's mail carries the connect setting** (owner R20 on #1811, option A, recorded in the owner's rulings file of 2026-10-19). For an address that is not connected, the first-page mail carries the record's type, name and value, so board OverviewDNS's line *"The same setting is in your first page's mail, so you can add it later from a desk."* is true and ships as drawn. The mail part is a follow-up issue on the mail surface. Until it lands, `overview.connect.later` says what the mail does today, and `docs/design/parity/OverviewDNS.allow` cites this ruling for the board's line.
